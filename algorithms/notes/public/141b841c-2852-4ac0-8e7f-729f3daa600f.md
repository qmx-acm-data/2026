# 快速幂

**快速幂通过不断平方，将计算乘方所需的乘法次数从 $O(p)$ 降到 $O(\log(p+1))$。**

需要掌握：乘方、取模，以及位运算中的奇偶判断和右移。

## 一、为什么可以将指数减半

设要计算 $a^p$，其中 $a$ 为底数，$p$ 为非负整数指数。

设 $q=\lfloor p/2\rfloor$，则：

$$
a^{2q}=(a^2)^q,
$$

$$
a^{2q+1}=a(a^2)^q.
$$

因此：

- **指数为偶数：** 底数平方，指数减半。
- **指数为奇数：** 先取出一份底数，再平方、减半。

每轮都能去掉约一半的指数，所以不需要逐次相乘。

### 从二进制理解

例如：

$$
13=(1101)_2=8+4+1,
$$

所以：

$$
a^{13}=a^8\times a^4\times a.
$$

不断平方，可以得到：

$$
a,\ a^2,\ a^4,\ a^8,\ldots
$$

**指数哪一位为 `1`，就乘入对应的项。**

## 二、怎样写成循环

设：

- `ans` 为已经取出的乘积，初始为 `1`。
- `base` 为当前底数，初始为 `a`。
- `exp` 为尚未处理的指数，初始为 `p`。

每轮执行：

```cpp
if (exp & 1) ans *= base;  // 指数为奇数，先取出一份底数
base *= base;             // 底数平方
exp >>= 1;                // 指数减半，向下取整
```

**三步完成后，`ans × base^exp` 的值不变。**

- 初始时，它等于 $a^p$。
- 结束时，`exp=0`，因此 `ans` 就是答案。

以上代码用于说明原理。实际乘方容易超过整数范围，竞赛中常要求计算乘方的余数。

## 三、模快速幂模板

设 $m$ 为正整数模数，计算：

$$
a^p\bmod m.
$$

由乘法取模的性质：

$$
(uv)\bmod m=((u\bmod m)(v\bmod m))\bmod m,
$$

可知**每一步都取模，不会影响最终余数**。

```cpp
long long qpow(long long a, long long p, long long mod) {
    long long ans = 1 % mod;
    long long base = a % mod;

    while (p > 0) {
        if (p & 1) ans = ans * base % mod;
        base = base * base % mod;
        p >>= 1;
    }

    return ans;
}
```

**使用条件：**

- `a >= 0`。
- `p >= 0`。
- `mod > 0`。
- 中间乘法不溢出；例如 `mod <= 10^9` 时，以上 `long long` 乘法安全。

三句关键操作：

| 代码 | 作用 |
| --- | --- |
| `p & 1` | 读取最低位，判断是否乘入当前底数 |
| `base = base * base % mod` | 准备下一位对应的幂 |
| `p >>= 1` | 丢掉已处理的最低位 |

## 四、手算：2 的 13 次方

初始 `ans=1`、`base=2`、`p=13`。为便于观察，下面省略取模。

| 本轮开始的 `p` | 本轮开始的 `base` | 最低位 | 更新后的 `ans` |
| --- | --- | --- | --- |
| `13` | $2$ | `1` | $1\times2=2$ |
| `6` | $4$ | `0` | $2$ |
| `3` | $16$ | `1` | $2\times16=32$ |
| `1` | $256$ | `1` | $32\times256=8192$ |

每轮处理完后，底数平方、指数右移。指数最终变为 `0`，得到：

$$
2^{13}=8192.
$$

实际乘入答案的是 $2^1、2^4、2^8$，对应 $13$ 的二进制中为 `1` 的三位。

## 五、边界与常见错误

### 指数为 0

循环不执行，直接返回 `1 % mod`，对应 $a^0=1$。

模板将 $0^0$ 也按空乘积返回 `1 % mod`；如果题目另有规定，需要单独处理。

### 模数为 1

任何整数对 `1` 取模都为 `0`。

因此，初始化写成：

```cpp
long long ans = 1 % mod;
```

这样也能正确处理 `p=0, mod=1`。

### 乘法溢出

> <span style="color: #d32f2f;"><strong>先乘再取模，仍然可能溢出。`% mod` 不能修复已经溢出的乘法。</strong></span>

模数很大时，在支持 `__int128` 的编译器中，将两处乘法改为：

```cpp
if (p & 1)
    ans = (long long)((__int128)ans * base % mod);

base = (long long)((__int128)base * base % mod);
```

**转换必须放在乘法前，乘完再转换就来不及了。**

### 求完整乘方

不能不检查范围就直接删掉 `% mod`。完整结果较大时，应使用高精度。

还要注意：最后一轮的平方已经不会再被使用，却仍可能溢出。普通整数版本若去掉取模，需要避免计算这次多余的平方。

## 六、复杂度与高精度扩展

指数每轮减半，普通整数版本：

- 时间复杂度：$O(\log(p+1))$。
- 额外空间：$O(1)$。

**快速幂减少的是乘法次数，乘法本身可以换成其他形式。**

高精度快速幂使用同一套流程，只将普通乘法替换为高精度乘法。

例如，麦森数题要求 $2^p-1$ 的末 $500$ 位，就在每次高精度乘法后保留末 $500$ 位，相当于对 $10^{500}$ 取模。

设保留位数为 $K$，一次竖式乘法需要 $O(K^2)$，则总时间复杂度为：

$$
O(K^2\log(p+1)).
$$

## 一句话记忆

> **指数为奇数，答案乘底数；每轮底数平方，指数减半。**
