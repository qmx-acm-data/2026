# C++ 模拟题笔记

> **题意读不透，先手搓题目给的小样例。**
>
> **复杂模拟通常状态多、流程长、操作复杂，尤其要盯住状态的更新时机。**
>
> **从实现角度看，所有题都可以当作模拟。板子题就是把算法思路一步步模拟成代码。**

## 一、模拟是什么

模拟就是**用计算机按题目规则一步步执行操作**。它通常码量大、操作多、思路繁复，中间状态多，出了错不容易查。考场上写错很浪费时间，所以写之前要想清楚，写的时候要分块。

## 二、题意读不透，先手搓样例

按「**初始状态 → 本步操作 → 更新后的状态**」手推，最后和样例输出对照。

- **推到一半卡住**，就回看那一步的规则。确认操作什么时候触发、谁先谁后、新值何时生效。
- **结果对不上**，有样例解释就找最早算错的一步。只有输出时，就把拿不准的规则按不同理解各推一遍。
- **两种理解都能推对**，就自己造一个能区分它们的小例子，再对照题面判断。

## 三、模拟的三大要素

### （一）状态

状态就是**事物在某一时刻的情况**，比如角色的位置和血量，或当前排队的人及其顺序。

| C++ 写法 | 能模拟什么 |
| --- | --- |
| 单个变量 | 一个值，比如 `hp` 记录血量，`open` 记录门是否打开 |
| 数组 | 按编号或坐标记录的一组值，比如 `score[i]` 记录分数，`grid[r][c]` 记录格子的占用情况 |
| 结构体 `struct` | 同一个对象的多个属性，比如角色的坐标和血量 |
| STL 容器 | `vector` 存可增减的序列，`queue` 模拟排队，`stack` 模拟一摞盘子 |

**更可以将状态广义化。** 

- **计数与累计量**：已走步数、累计得分、还剩几次。
- **标记**：某格是否访问过、某个开关是否打开。
- **进度**：当前处理到第几条指令、第几秒。
- **容器的内容本身**：（数据结构）队列里排着谁、栈里有什么。
- **树与图**：某个时刻的树与图也可以是一个状态

### （二）操作

操作就是**对状态做的事**。

| C++ 写法 | 能模拟什么 |
| --- | --- |
| 赋值 | 直接改变状态，比如 `open = true` 表示开门 |
| 运算 | 按规则计算变化，比如 `hp -= damage` 表示扣血 |
| 函数 | 把多条语句组成一次操作，比如调用 `move()` 完成一次移动 |

### （三）过程

过程就是**操作怎样一步步执行**。

| C++ 写法 | 能模拟什么 |
| --- | --- |
| 语句顺序 | 先后关系，比如先算候选坐标，再检查是否越界 |
| 条件判断 `if` | 满足条件才执行，比如位置合法才移动 |
| 循环 `for`、`while` | 重复执行，比如一轮一轮处理操作 |

## 四、写模拟题的技巧

**① 动手前先把流程写在纸上。** 复杂模拟状态多、流程长、操作复杂，尤其要盯住更新时机。

- 列状态表：记清初值、在哪一步修改、每轮重置还是跨轮保留。
- 把一轮分阶段：标清每步读的是旧值还是更新后的值。**需要同时更新时，先用旧值算完，再统一写回。**

**② 模块化。** 把每个部分写成函数、结构体或类。操作复杂就拆成小步，比如「算位置 → 判合法 → 更新状态」，一次移动改动了坐标、计数和占用标记就逐项核对。

**③ 统一概念转化。** 重复出现的表达抽成一个函数。比如「YY-MM-DD 时:分」只写一次转秒数的函数，之后全部按秒计算，避免概念混淆。

**④ 分块调试。** 每写完一个模块，就用小样例单独验证。重点测同一轮里操作怎样互相影响，以及上一轮结果怎样传到下一轮。

**⑤ 照纸上的步骤写。** 想到什么写什么容易漏步、写乱顺序，按草稿纸上的流程往下写。

## 五、板子题也是模拟

板子题把算法的步骤写成代码。BFS 也可以按「状态、操作、过程」这三类来理解。

- **状态**。队列存待处理的节点，`dist` 记录距离。
- **操作**。出队、遍历邻居、记录距离、入队。
- **过程**。循环处理队首。发现新节点时，先记录距离，再把它入队。之后遇到同一个节点，就能用 `dist` 判断它已经入过队。

## 六、注意的常见边界条件

| 检查项 | 容易出错的地方 |
| --- | --- |
| 空与满 | 取栈顶、队首或弹出元素前先判空。往固定容量数组写入前先确认还有空间。 |
| 下标 | 从 `0` 开始的长度为 `n` 的数组，合法下标是 `0` 到 `n - 1`。访问网格前要检查行和列。 |
| 特殊数据 | 专门测 `0`、负数、重复元素以及刚好达到上限的情况。 |
| 初始化 | 全局和 `static` 局部 `int` 数组默认清零。普通局部 `int a[100];` 的元素未初始化，`int a[100]{};` 会清零。`vector<int> v(n);` 有 `n` 个 `0`，`vector<int> v;` 是空容器。 |
| 整除与取模 | C++ 整数除法向零截断，`-5 / 3 == -1`，`-5 % 3 == -2`。处理循环下标时，若 `n > 0`，先算 `r = i % n`，若 `r < 0` 就加上 `n`。 |

**既然模拟都一定要注意边界，那么所有类型的题都应该注意边界。**
