# 高精度整数运算学习文档（C++ 零基础入门）

> 学习目标：理解大整数如何存储，以及加、减、乘、除的基本原理。
>
> 本文使用 C++，先讨论非负整数；减法先限定为大数减小数，除法要求除数大于 0。暂不涉及负数和小数。

高精度整数运算可以理解为：**当一个整数太大，普通变量存不下时，用数组保存它的每一位，再模拟竖式计算。**

## 1. 为什么需要高精度？

C++ 常用的整数类型，能保存的数字大小有限：

| 类型 | 通常占用空间 | 能保存的最大正整数 |
| --- | --- | --- |
| `int` | 4 字节 | 约 2.1 × 10⁹ |
| `long long` | 8 字节 | 约 9.2 × 10¹⁸ |

例如：

```text
123456789012345678901234567890
```

这个数有 30 位，已经超过了 `long long` 的范围。

即使换成 `double`，也不能保证每一位整数都准确。因此，我们需要换一种保存和计算的方法。

这里的“高精度”主要解决的是：**整数很大，但每一位都必须算准确。**

## 2. 大整数怎么保存？

分两步：**用字符串读入，用数组存每一位。**

### 2.1 用字符串读入

```cpp
string s;
cin >> s;
```

输入 `12345` 后，`s` 保存的是字符：

```text
'1' '2' '3' '4' '5'
```

注意：字符 `'5'` 和整数 `5` 不一样。把数字字符转成整数，可以写：

```cpp
int x = s[0] - '0';
```

如果 `s[0]` 是 `'5'`，那么 `x` 就是整数 `5`。

### 2.2 倒序保存每一位

把每一位倒着放入数组：

```text
原来的数字：12345

数组下标：  0  1  2  3  4
数组内容：  5  4  3  2  1
对应数位： 个 十 百 千 万
```

这样保存，是因为加法、减法、乘法通常都从个位开始计算。

C++ 可以使用动态数组 `vector<int>`：

```cpp
vector<int> a;

for (int i = (int)s.size() - 1; i >= 0; i--) {
    a.push_back(s[i] - '0');
}
```

这里需要认识三个用法：

- `s.size()`：字符串的长度。
- `a.push_back(x)`：把 `x` 放到数组末尾。
- `a[i]`：访问下标为 `i` 的元素，数组下标从 `0` 开始。

**记忆要点：数组下标 `0` 对应个位，下标越大，对应的数位越高。**

## 3. 高精度加法：重点是“进位”

### 3.1 竖式计算原理

先看普通竖式：

```text
   789
+  456
------
  1245
```

从右向左计算：

| 数位 | 计算 | 当前位留下 | 向下一位进位 |
| --- | --- | --- | --- |
| 个位 | 9 + 6 = 15 | 5 | 1 |
| 十位 | 8 + 5 + 1 = 14 | 4 | 1 |
| 百位 | 7 + 4 + 1 = 12 | 2 | 1 |
| 千位 | 剩余进位为 1 | 1 | 0 |

你只需要记住：

```cpp
当前位 = 总和 % 10;
进位 = 总和 / 10;
```

其中：

- `% 10` 是取个位，例如 `15 % 10 = 5`。
- 对非负整数，整数 `/ 10` 是去掉个位，例如 `15 / 10 = 1`。

### 3.2 完整代码

以下代码可以直接运行，输入为两个只含数字的非负整数字符串：

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    vector<int> a, b, c;

    // 倒序保存第一个整数
    for (int i = (int)s1.size() - 1; i >= 0; i--) {
        a.push_back(s1[i] - '0');
    }

    // 倒序保存第二个整数
    for (int i = (int)s2.size() - 1; i >= 0; i--) {
        b.push_back(s2[i] - '0');
    }

    int carry = 0;  // 进位

    // 有数字没算完，或者还有进位，就继续计算
    for (int i = 0;
         i < (int)a.size() || i < (int)b.size() || carry != 0;
         i++) {

        int sum = carry;

        if (i < (int)a.size()) {
            sum += a[i];
        }

        if (i < (int)b.size()) {
            sum += b[i];
        }

        c.push_back(sum % 10);
        carry = sum / 10;
    }

    // 去掉多余的高位 0，至少保留一位
    while (c.size() > 1 && c.back() == 0) {
        c.pop_back();
    }

    // 数组中是倒序保存的，因此倒着输出
    for (int i = (int)c.size() - 1; i >= 0; i--) {
        cout << c[i];
    }

    cout << '\n';
    return 0;
}
```

输入：

```text
99999999999999999999
1
```

输出：

```text
100000000000000000000
```

### 3.3 理解代码的关键

重点理解这四步：**读入 → 倒序保存 → 逐位相加 → 倒序输出。**

- `carry` 保存上一位产生的进位。
- `sum` 保存当前两位数字与进位的总和。
- 两个数的长度可能不同，访问数组前需要判断下标是否合法。
- 最后一次进位也要写入结果，例如 `999 + 1 = 1000`。
- `c.back()` 访问数组最后一个元素，`c.pop_back()` 删除最后一个元素。

## 4. 高精度减法：重点是“借位”

### 4.1 竖式计算原理

先学“大数减小数”，保证结果非负。

例如：

```text
  302
- 178
-----
  124
```

从个位开始，每一位都计算：

```text
当前差值 = 被减数当前位 - 减数当前位 - 上一位借走的 1
```

如果差值小于 `0`：

```text
当前差值加 10
向更高一位借 1
```

### 4.2 核心代码

下面的片段假设 `a`、`b` 已倒序保存，且 `a` 表示的数不小于 `b`。计算前令 `borrow = 0`，在遍历 `a` 的循环内执行：

```cpp
int diff = a[i] - borrow;

if (i < (int)b.size()) {
    diff -= b[i];
}

if (diff < 0) {
    diff += 10;
    borrow = 1;
} else {
    borrow = 0;
}

c.push_back(diff);
```

其中，`borrow` 表示借位：

- `borrow = 1`：当前位向更高一位借了 1，下一轮需要扣除。
- `borrow = 0`：没有借位。

### 4.3 比较大小与处理高位零

减法还需要掌握两个知识点：

1. **比较大小**：先比较有效位数，位数相同就从最高位开始比较。
2. **删除多余的高位零**：例如 `1000 - 999 = 1`，不能输出 `0001`。

如果允许输入带前导零，例如 `00012`，应先去掉多余的前导零，再比较有效位数。

对于倒序保存的结果数组，可以这样删除多余的高位零：

```cpp
while (c.size() > 1 && c.back() == 0) {
    c.pop_back();
}
```

**注意：至少保留一位，数字 `0` 也需要用一个 `0` 表示。**

## 5. 高精度乘法：建议分两步学习

### 5.1 大整数 × 普通小整数

例如：

```text
12345678901234567890 × 3
```

从低位到高位，每一位计算：

```text
临时结果 = 当前数字 × 乘数 + 进位
当前位 = 临时结果 % 10
新进位 = 临时结果 / 10
```

这和加法很像，但有一个区别：**乘法的最后进位可能有多位，需要继续拆分。**

例如，处理完大整数的所有数位后，如果 `carry` 仍大于 `0`，可以继续执行：

```cpp
while (carry > 0) {
    c.push_back(carry % 10);
    carry /= 10;
}
```

临时结果和进位应根据乘数范围选择足够大的类型，必要时使用 `long long`。乘数为 `0` 时，结果也要正确保存为 `0`。

### 5.2 大整数 × 大整数

例如：

```text
12345678901234567890 × 98765432109876543210
```

基本规律是：

> 数组 `a` 的第 `i` 位，乘数组 `b` 的第 `j` 位，产生的结果先累加到数组 `c` 的第 `i + j` 位。

核心形式：

```cpp
c[i + j] += a[i] * b[j];
```

可以用一个简单例子理解：

```text
个位 × 个位 → 个位
个位 × 十位 → 十位
十位 × 十位 → 百位
```

这对应的就是下标相加：

```text
0 + 0 = 0
0 + 1 = 1
1 + 1 = 2
```

实现时，需要先为结果数组分配足够空间，再安排好进位时机，避免某个位置累加过大。

## 6. 高精度除法：只学“大整数 ÷ 小整数”

### 6.1 从最高位开始计算

除法要从**最高位向最低位**计算，这一点和加法不同。

例如 `1234 ÷ 5`：

| 读入当前位 | 上一步余数 × 10 + 当前数字 | 本次商位 | 新余数 |
| --- | --- | --- | --- |
| 1 | 1 | 0 | 1 |
| 2 | 12 | 2 | 2 |
| 3 | 23 | 4 | 3 |
| 4 | 34 | 6 | 4 |

得到：

```text
商：246
余数：4
```

### 6.2 核心公式

```cpp
current = remainder * 10 + digit;
quotientDigit = current / divisor;
remainder = current % divisor;
```

变量含义：

| 变量 | 含义 |
| --- | --- |
| `digit` | 当前读入的一位数字 |
| `remainder` | 余数，初始为 0 |
| `current` | 上一步余数与当前数字组成的数 |
| `divisor` | 除数 |
| `quotientDigit` | 当前得到的一位商 |

需要注意：

- 除数必须大于 `0`。
- 中间变量要使用足够大的类型，避免 `remainder * 10` 溢出。
- 商的开头可能出现多余的 `0`，输出前需要处理。
- 如果被除数小于除数，商应为 `0`，余数为被除数。
- 如果输入保存在字符串中，可以从左往右处理；如果使用倒序数组，则需要从数组末尾开始处理。

## 7. 初学时最容易出错的地方

| 常见问题 | 正确做法 |
| --- | --- |
| 把字符直接当作数字 | 使用 `s[i] - '0'` |
| 忘记数组是倒序保存的 | 下标 `0` 对应个位 |
| 忘记最后一次进位 | 用 `999 + 1` 检查 |
| 两个数长度不同，数组访问越界 | 访问前判断下标是否小于长度 |
| 结果是 `0`，却没有输出 | 删除多余零时至少保留一位 |
| 把大整数先转成 `long long` | 直接从字符串逐位处理 |
| 乘法中间结果溢出 | 根据乘数范围选择类型，必要时用 `long long` |
| 减法前没有判断大小 | 先保证被减数不小于减数 |
| 除法也从个位开始计算 | 除法从最高位开始计算 |
