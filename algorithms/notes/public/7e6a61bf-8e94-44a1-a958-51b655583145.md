## 1. 贪心策略

两条基本方向：

- **从最小 / 最大开始**：优先处理成本最低、收益最高、结束最早等对象。
- **从最左 / 最右开始**：原顺序有意义时，先确定边界位置，将问题缩小。

### §1.1 从最小 / 最大开始贪心

**识别特征**：可以重排；元素对目标的贡献或资源消耗存在可比较的优势。

“预算内购买最多件商品”属于这一类：**相同件数下，越便宜越省预算，因此按价格升序取。**

反过来，若目标是用最少箱子装下可以自由分装的固定总量，应优先使用容量最大的箱子。

| 问题 | 每次选择 | 理由 |
| --- | --- | --- |
| 预算固定，最大化购买件数 | 最便宜的 | 相同件数下消耗最少 |
| 总量固定，最小化箱子数量 | 容量最大的 | 相同箱数下能容纳最多 |

**边界**：如果商品价值不同，目标变成总价值最大，“便宜优先”就不再有同样的证明。

**练习**：[1833. 雪糕的最大数量](https://leetcode.cn/problems/maximum-ice-cream-bars/)、[3074. 重新分装苹果](https://leetcode.cn/problems/apple-redistribution-into-boxes/)。

### §1.2 单序列配对

同一序列中的元素需要配对，常结合排序和双指针。配对方向取决于目标，不能统一记成“最小配最大”。

**模型一：救生艇。** 每船至多两人、重量和不超过 limit，每个人均能独自乘船。

- 最重的人 H 必须被安排。
- 若 H 连最轻的人 L 都带不动，只能独自乘船。
- 否则安排 H、L 同船。

**交换证明**：若最优解原本让 H 与 X、L 与 Y 同船，可改为 H 与 L、X 与 Y。由于 Y≤H 且 H+X≤limit，有 X+Y≤limit，船数不增加。有人原本独行时也可类似调整。

**模型二：最小化最大数对和。** 将最小值与最大值配对。若最大值与较大的数相配，交换搭档，把最小值配给最大值，不会增大两对中的最大和。

**练习**：[881. 救生艇](https://leetcode.cn/problems/boats-to-save-people/)、[1877. 数组中最大数对和的最小值](https://leetcode.cn/problems/minimize-maximum-pair-sum-in-array/)、[561. 数组拆分](https://leetcode.cn/problems/array-partition/)。

### §1.3 双序列配对

两组对象之间匹配，先考虑排序后能否消除交叉或避免资源浪费。

**典型模型：分发饼干。** 两组均升序，用尽量小但足够大的饼干满足需求最小的孩子。

- 饼干不足以满足当前最小需求：也不可能满足后面的需求，直接跳过。
- 能满足：可以安全匹配，把更大的饼干留给后面。

**证明**：从最优匹配出发，将当前孩子与当前饼干匹配。若原本分别匹配了其他对象，可以交换归属：较大的饼干仍足以满足原本由当前饼干满足的孩子，匹配数量不会减少。

“学生与座位”则是另一种同序匹配：对于 x≤y、u≤v，消除交叉不会增加距离和：

$$
|x-u|+|y-v|\le |x-v|+|y-u|.
$$

**练习**：[455. 分发饼干](https://leetcode.cn/problems/assign-cookies/)、[2037. 使每位学生都有座位的最少移动次数](https://leetcode.cn/problems/minimum-number-of-moves-to-seat-everyone/)。

### §1.4 从最左 / 最右开始贪心

**识别特征**：位置关系不能打乱；确定边界位置后，剩余部分仍是同类问题。

**例：只允许增加元素，使数组严格递增。** 令最终数组为 b：

$$
b_1=a_1,\qquad b_i=\max(a_i,b_{i-1}+1).
$$

选择满足当前限制的最小值，既减少当前花费，也使后续下界最低。

**归纳证明**：任意合法方案 c 都满足 c₁≥b₁；若 cᵢ₋₁≥bᵢ₋₁，则 cᵢ≥max(aᵢ,cᵢ₋₁+1)≥bᵢ。因此贪心逐项不大于任何合法方案，总增加量最少。

**练习**：[1827. 最少操作使数组递增](https://leetcode.cn/problems/minimum-operations-to-make-the-array-increasing/)、[2027. 转换字符串的最少操作次数](https://leetcode.cn/problems/minimum-moves-to-convert-string/)。

### §1.5 划分型贪心

把序列划分为若干段，目标为最大或最小段数。关键是确定切分边界，而不只是决定扫描方向。

- **最大化段数**：尝试尽早切出一个合法段。
- **最小化段数**：尝试尽量延长当前合法段。

这只是候选方向，仍依赖具体约束。

**例：每段字符不重复，最小化段数。** 扫描到即将出现重复字符时切分。

**证明**：贪心取最长合法前缀。把最优划分的第一段向后扩展到该位置，只会吞掉后续若干段或段的前缀，剩余部分仍无重复，段数不会增加。然后处理后缀。

**适用条件**：该证明使用了“合法段的子段仍合法”。若每段有额外收益、长度下限等条件，就需要重新分析。

**练习**：[2405. 子字符串的最优划分](https://leetcode.cn/problems/optimal-partition-of-string/)、[1221. 分割平衡字符串](https://leetcode.cn/problems/split-a-string-in-balanced-strings/)、[2294. 划分数组使最大差为 K](https://leetcode.cn/problems/partition-array-such-that-maximum-difference-is-k/)。

### §1.6 先枚举，再贪心

整体选择互相牵制时，尝试固定一个目标值、边界或数量，使其余选择能够独立确定。

**例：拿出最少数目的魔法豆。** 固定非空袋子的最终豆数为 x：

- 少于 x 的袋子全部清空。
- 不少于 x 的袋子都保留 x 个；清空其中任何一袋都不会更优。

排序为 a₀≤…≤aₙ₋₁，只需枚举原数组中的值作为 x。目标值落在两个原值之间时，提高到右边原值，保留袋数不变，保留豆数更多。

因此答案为：

$$
\min_{0\le i<n}\left(\sum_j a_j-a_i(n-i)\right).
$$

**要点**：既要证明固定条件后的选择最优，也要证明枚举范围完整。

**练习**：[2171. 拿出最少数目的魔法豆](https://leetcode.cn/problems/removing-minimum-number-of-magic-beans/)。

### §1.7 交换论证法

除了验证策略，交换论证也能直接推出排序依据。

**例：排队等待时间之和最小。** 相邻两人的耗时为 x、y，之前的总耗时为 T：

$$
\text{先 x 后 y：}2T+x,\qquad
\text{先 y 后 x：}2T+y.
$$

交换不会改变后续人的等待时间，因此 x≤y 时，x 在前不劣。不断消除逆序，得到按耗时升序排列的最优方案。

若每个人有等待权重 wᵢ，则相邻比较变为：

$$
xw_y\le yw_x.
$$

当权重为正时，对应按“耗时 / 权重”升序；实现可用交叉乘法比较，并注意溢出。

**边界**：相邻比较推出的规则必须形成一致的顺序。C++ 比较器需要满足严格弱序，不能用 `<=` 代替严格比较，也不能只检查两个元素就忽略全局约束。

### §1.8 相邻不同

设总元素数为 n，最高频次为 m。常见三个结论：

| 问题 | 结论 |
| --- | --- |
| 重排后相邻元素都不同是否可行 | m≤n−m+1 |
| 每次删除两个不同元素，最多操作多少次 | min(⌊n/2⌋, n−m) |
| 每次删除至多两个不同元素，全部删除最少多少次 | max(⌈n/2⌉, m) |

**理解方式**：最高频元素需要由其他元素分隔；不同元素配对同时受“总数的一半”和“非最高频元素数量”限制。

构造相邻不同的排列时，可用最大堆：当前使用的元素暂时不放回，下一步选择后再恢复，避免连续使用同一种元素。可行性还需由频次数量条件保证。

**练习**：[767. 重构字符串](https://leetcode.cn/problems/reorganize-string/)。

### §1.9 反悔贪心

先做暂时选择，违反约束时替换之前最不合适的一项，使已选集合保留更多后续机会。常用堆维护可替换对象。

**典型模型：课程表 III。** 每门课有耗时 t 和截止时间 d，求最多完成多少门。

1. 按截止时间升序处理。
2. 加入当前课程，累加耗时，用大根堆记录已选课程耗时。
3. 若总耗时超过当前截止时间，删除耗时最长的一门。

**关键依据**：

- 截止时间有序，新增课程之前，已选集合按该顺序可行。
- 若必须少选一门，删除最长课程使当前集合剩余耗时最小。
- 删除一次即可恢复当前截止时间约束：被删除课程的耗时至少等于新课程耗时，删除后总耗时不超过加入前的总耗时。
- 删除旧课时，旧课之后的完成时间只会提前；新课也能在当前截止时间前完成。

完整最优性论证还需结合前缀最优数量与替换关系，不能只凭“删最长的省时间”就断言所有调度问题都适用。

```cpp
int scheduleCourse(vector<vector<int>>& courses) {
    sort(courses.begin(), courses.end(),
         [](const auto& a, const auto& b) { return a[1] < b[1]; });

    priority_queue<int> chosen;
    long long total = 0;
    for (const auto& c : courses) {
        total += c[0];
        chosen.push(c[0]);
        if (total > c[1]) {
            total -= chosen.top();
            chosen.pop();
        }
    }
    return (int)chosen.size();
}
```

**练习**：[630. 课程表 III](https://leetcode.cn/problems/course-schedule-iii/)、[1642. 可以到达的最远建筑](https://leetcode.cn/problems/furthest-building-you-can-reach/)、[871. 最低加油次数](https://leetcode.cn/problems/minimum-number-of-refueling-stops/)。

## 2. 区间贪心

先确定优化目标，再确定排序依据。**端点相等是否冲突，必须按题意区分。**

| 小节 | 目标 | 常见排序 / 维护方式 | 核心选择 |
| --- | --- | --- | --- |
| §2.1 区间覆盖 | 最少区间覆盖目标线段 | 左端点升序 | 在能够接上的区间中选右端点最远的 |
| §2.2 区间分组 | 最少组容纳所有区间，同组不相交 | 左端点升序 + 小根堆 | 能复用最早结束的组就复用，否则新开 |
| §2.3 区间选点 | 最少点命中所有区间 | 右端点升序 | 在首个未命中区间的右端点选点 |
| §2.4 不相交区间 | 选最多个互不相交区间 | 右端点升序 | 选最早结束且与已选兼容的区间 |
| §2.5 合并区间 | 求区间并集 | 左端点升序 | 相交则延长，否则开始新段 |

### §2.1 区间覆盖

维护连续覆盖边界 cur。在所有 l≤cur 的候选中取最大的右端点，作为下一边界。若无法前进，则存在缺口。

**始终领先证明**：相同步数后，假设贪心覆盖不短于任意比较方案。比较方案下一步能接上的区间，贪心也能接上；贪心选最远端点，因此下一步仍不落后。

**复杂度**：排序后单调扫描，O(n log n)。候选扫描指针不应每次从头开始。

**练习**：[1024. 视频拼接](https://leetcode.cn/problems/video-stitching/)、[45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)。

### §2.2 区间分组

按左端点处理，小根堆维护每组的最后结束时间。若最早结束的组仍与当前区间冲突，则所有组都冲突，必须新开一组。

**下界证明**：每次新开组时，所有已有组的末尾区间与当前区间在当前起点同时存在，因此任何方案都至少需要这么多组。算法每次增加组数都有必要，最终最优。

- 半开区间或允许端点相接：end≤start 可以复用。
- 闭区间且相接算冲突：end<start 才能复用。

**练习**：[2406. 将区间分为最少组数](https://leetcode.cn/problems/divide-intervals-into-minimum-number-of-groups/)。

### §2.3 区间选点

对闭区间按右端点升序。当前区间未命中时，在其右端点选点。

**交换证明**：最早结束的未命中区间必须被某个点 p 命中。将 p 右移到该区间右端点 r：对任何原本包含 p、且右端点不早于 r 的剩余区间，都有 l≤p≤r≤右端点，因此仍被命中。

**练习**：[452. 用最少数量的箭引爆气球](https://leetcode.cn/problems/minimum-number-of-arrows-to-burst-balloons/)。

### §2.4 不相交区间

按右端点升序，每次保留能够接上的最早结束的区间。

**交换证明**：将最优方案第一个区间替换为贪心区间，它结束得更早或相同，后续安排仍合法，数量不变。对剩余区间重复。

```cpp
int eraseOverlapIntervals(vector<vector<int>>& intervals) {
    sort(intervals.begin(), intervals.end(),
         [](const auto& a, const auto& b) { return a[1] < b[1]; });

    int kept = 0, end = 0;
    for (const auto& p : intervals) {
        if (kept == 0 || p[0] >= end) {  // 允许端点相接
            ++kept;
            end = p[1];
        }
    }
    return (int)intervals.size() - kept;
}
```

**边界**：若各区间收益不同，最大数量改为最大收益，最早结束策略一般失效，通常需要加权区间 DP。

**练习**：[435. 无重叠区间](https://leetcode.cn/problems/non-overlapping-intervals/)、[646. 最长数对链](https://leetcode.cn/problems/maximum-length-of-pair-chain/)。

### §2.5 合并区间

按左端点排序，重叠时更新右端点为两者最大值，否则保存当前段并开启下一段。

该模型主要是有序扫描，不必强行解释成最优化贪心。它也是理解覆盖边界、区间连通块和划分字母区间的基础。

**练习**：[56. 合并区间](https://leetcode.cn/problems/merge-intervals/)、[763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)。

### §2.6 其他区间贪心

典型扩展是按时间扫描，把当前可执行任务加入小根堆，优先处理最早过期的任务。

**直觉与证明方向**：若当前处理较晚过期的任务，而较早过期的任务安排在未来，可以交换处理顺序，不损失可行性；若后者未被安排，则替换当前任务也不减少完成数量。

该规则依赖单位处理时长、释放时间和截止时间等具体条件；任意时长、权重的调度不能直接照搬。

**练习**：[1705. 吃苹果的最大数目](https://leetcode.cn/problems/maximum-number-of-eaten-apples/)、[1353. 最多可以参加的会议数目](https://leetcode.cn/problems/maximum-number-of-events-that-can-be-attended/)。

## 3. 字符串贪心

### §3.1 字典序最小 / 最大

字典序由第一个不同位置决定，因此通常从左向右确定字符。

**正确策略**：每一位选择最小 / 最大的、且仍存在合法后缀的字符。

“当前字符最小”与“仍可补全”缺一不可。若资源有限，常需计数判断；若允许删除已有字符，可能结合单调栈；若有复杂限制，则可能需要 DP 辅助判断可行性。

**简单例子**：最多把一个 6 改成 9，应改最靠左的 6，因为其位权最高。

**练习**：[1323. 6 和 9 组成的最大数字](https://leetcode.cn/problems/maximum-69-number/)。

### §3.2 回文串贪心

回文约束的核心是对称位置配对，奇数长度最多有一个中心。

- **最长回文串长度**：每种字符先贡献最大偶数个，若有剩余再取一个中心。
- **字典序最小回文串**：在操作规则允许独立选择左右字符时，让靠前位置尽可能小，并同步满足对称关系。

长度、字典序、修改次数是不同目标，应分别分析。只统计奇偶次数不能解决所有回文构造问题。

**练习**：[409. 最长回文串](https://leetcode.cn/problems/longest-palindrome/)、[2697. 字典序最小回文串](https://leetcode.cn/problems/lexicographically-smallest-palindrome/)。

### §3.3 合法括号字符串

对于单种括号，令 balance 为左括号数减右括号数。合法条件：任意前缀 balance≥0，最终 balance=0。

最少插入模型中：遇到无法匹配的右括号，必须补左括号；扫描后剩下多少左括号，就必须补多少右括号。每次补充对应必要成本，因此最优。

允许删除、包含 `*` 或多种括号时，状态和策略会改变，可能需要栈、可达 balance 范围或 DP。原题单将本节关联到数据结构题单的括号专题。

## 4. 数学贪心

### §4.1 基础：整除、余数与必要成本

**例：每轮完成同类任务 2 个或 3 个，求最少轮数。**

- 数量为 1 时无解。
- 其余尽量按 3 个分组；余 2 时单独一组，余 1 时把 `3+1` 调整为 `2+2`。

每类数量 c≥2 时，答案为：

$$
\left\lceil\frac c3\right\rceil.
$$

每轮最多处理 3 个给出下界，而上述构造达到下界。

**练习**：[2244. 完成所有任务需要的最少轮数](https://leetcode.cn/problems/minimum-rounds-to-complete-all-tasks/)。

### §4.2 乘积贪心

先检查正负号、0、选择数量及整数限制，再谈“选大的”或“尽量接近”。

例如数组中选三个数使乘积最大，排序后比较：

- 最大的三个数。
- 最小的两个数与最大的一个数。

后者可能利用两个负数得到更大的正积。

**注意**：“固定项数、固定总和时更均衡”不能直接推出“应该拆成多少项”；改变项数需要另外证明。

**练习**：[628. 三个数的最大乘积](https://leetcode.cn/problems/maximum-product-of-three-numbers/)。

### §4.3 排序不等式

对于 a≤b、x≤y：

$$
(ax+by)-(ay+bx)=(b-a)(y-x)\ge0.
$$

因此，两组数可自由配对时：

- 同序配对，乘积和最大。
- 反序配对，乘积和最小。

结论不要求元素全为正，但要求允许相应重排。证明可通过交换消除逆序完成。

### §4.4 均值不等式：均衡与集中

固定项数和总和的非负实数，乘积在相等时达到最大。两个数可直接写成：

$$
xy=\frac{(x+y)^2-(x-y)^2}{4}.
$$

总和固定时，差越小，乘积越大。若要求整数或互不相同，就在合法范围内分析均衡形态。

平方和则方向相反：

$$
x^2+y^2=\frac{(x+y)^2+(x-y)^2}{2}.
$$

对于固定总和的非负数，增大差距会增加平方和，但具体能集中到何种程度受上下界等限制。

**操作比较法**：对于整数 x<y，把 `x、y` 改成 `x+1、y−1`，乘积变化为：

$$
(x+1)(y-1)-xy=y-x-1.
$$

若该值为正且调整合法，就能证明原方案尚不最优。

### §4.5 中位数贪心

**模型**：选择基准值 x，最小化等权绝对距离和：

$$
f(x)=\sum_{i=1}^{n}|a_i-x|.
$$

排序后选中位数最优。奇数长度最优值为中间值；偶数长度两个中间值之间的任意值都最优。

**证明一：两端配对。** 对 u≤v：

$$
|u-x|+|v-x|\ge v-u,
$$

当 x∈[u,v] 时取等号。最小与最大、次小与次大依次配对，得到相互嵌套的区间，中位数同时落在这些区间内。奇数长度时，剩余的中间项也在中位数处取得 0。

**证明二：相邻费用差。** 对整数数据，令 L(x)=#{i:aᵢ≤x}：

$$
f(x+1)-f(x)=2L(x)-n.
$$

差值随 x 单调不减。右侧元素更多时右移有利，左侧更多时右移不利，最低点位于中位数或两个中间值之间的平台。

**适用边界**：

- 绝对距离和对应中位数。
- 平方距离和在实数域对应平均数；整数目标还需比较邻近整数。
- 加权绝对距离和对应带权中位数。
- 操作转化需确认各元素的费用能够相加，且目标值或操作之间没有遗漏的限制。

**练习**：[462. 最小操作次数使数组元素相等 II](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements-ii/)、[2448. 使数组相等的最小开销](https://leetcode.cn/problems/minimum-cost-to-make-array-equal/)。

### §4.6 归纳法：连续可达范围

正整数硬币每枚最多用一次，升序处理。维护已处理硬币可以组成全部 `[0,s]`，且总和为 s。

下一枚面值为 x：

- x≤s+1：不使用与使用 x 的范围分别为 `[0,s]`、`[x,x+s]`，可连接成 `[0,s+x]`。
- x>s+1：后续硬币都不小于 x，无法填补缺口 s+1。

若可补硬币，应补 s+1：任何大于它的面值都无法补缺口，较小面值扩展范围又不如它大。补入后范围变为 `[0,2s+1]`，并重新检查当前原硬币。

```cpp
int minPatches(vector<int>& nums, long long target) {
    sort(nums.begin(), nums.end());
    long long reach = 0;
    int i = 0, answer = 0;

    while (reach < target) {
        if (i < (int)nums.size() && nums[i] <= reach + 1) {
            reach += nums[i++];
        } else {
            reach += reach + 1;
            ++answer;
        }
    }
    return answer;
}
```

代码要求面值为正，并假设 `2*reach+1` 在 `long long` 范围内；更大目标需要防溢出处理。

**练习**：[2952. 需要添加的硬币的最小数量](https://leetcode.cn/problems/minimum-number-of-coins-to-be-added/)、[330. 按要求补齐数组](https://leetcode.cn/problems/patching-array/)。

### §4.7 其他数学贪心

优先分析：一次操作的变化量、奇偶与余数限制、必需成本、答案上下界，以及能否构造达到这些界的方案。

特殊数列可以产生特殊贪心规则。例如斐波那契找和问题中“优先选最大可用项”依赖数列性质，不能推广成任意面额找零。

**练习**：[1414. 和为 K 的最少斐波那契数字数目](https://leetcode.cn/problems/find-the-minimum-number-of-fibonacci-numbers-whose-sum-is-k/)。

### 例：柠檬水找零

收到 20 元，需要找 15 元时，优先用 `10+5`，而非三张 5 元。

两种做法相比，前者多保留两张 5 元、少保留一张 10 元。两张 5 元能替代一张 10 元用于找零，反过来不总成立，因此保留 5 元更有灵活性。

这类题可以寻找**资源替代关系**：一种资源能完成另一种资源的用途，并且还能完成额外用途时，应尽量保留更灵活的资源。

**练习**：[860. 柠檬水找零](https://leetcode.cn/problems/lemonade-change/)、[135. 分发糖果](https://leetcode.cn/problems/candy/)。

## 6. 构造题

先区分目标：只需一个合法方案，还是还要最大化、最小化或控制字典序？证明分别检查合法性、可完成性和最优性。

常用切入点：

- 成对抵消或对称安排。
- 先固定最小值、最大值等边界元素。
- 构造时维护剩余元素的简单结构。
- 从极端可行方案出发，逐步调整到目标。

**例：增减字符串匹配。** 用 `0..n` 构造排列，I 表示相邻递增，D 表示相邻递减。维护剩余范围 `[low,high]`：I 取 low，D 取 high，最后放唯一剩余值。

**证明**：取最小值后，后续任意值都更大；取最大值后，后续任意值都更小。当前约束得到保证，剩余范围仍连续，能够继续构造。

**练习**：[942. 增减字符串匹配](https://leetcode.cn/problems/di-string-match/)、[1304. 和为零的 N 个不同整数](https://leetcode.cn/problems/find-n-unique-integers-sum-up-to-zero/)。构造存在不等于一定涉及最优化贪心。

## 8. 其他与关联模型

### 8.1 最优合并与堆

每次合并两堆，代价等于重量和，求总代价最小。对非负重量，每次合并最小两堆，用小根堆维护。

**证明方向**：合并过程形成二叉树，总成本是“叶子权重 × 深度”的总和。可将两个最小权重安排为最深的一对兄弟而不增大代价，再将它们缩为一个新节点，归纳得到算法。

堆只负责 O(log n) 提取极值，正确性来自上述交换与归纳。取前 k 大、多路归并也能用堆，但证明依据不同。

### 8.2 按位贪心

最大化非负二进制整数时，一位的权重超过所有更低位之和，因此可从高位向低位尝试置 1。

真正的难点是：固定此前高位、尝试当前位后，能否判断存在合法补全？常结合位运算、Trie、线性基或其他可行性检查。

### 8.3 图论贪心

| 算法 | 贪心选择 | 依据 / 前提 |
| --- | --- | --- |
| Kruskal | 按权值升序，选不成环的边 | 最小生成树割性质、交换论证 |
| Prim | 选跨越当前点集与外部的最轻边 | 割性质 |
| Dijkstra | 确定暂定距离最小的未确定点 | 标准版本要求非负边权 |

拟阵能够统一解释部分按权值选择的贪心问题，例如最小生成树，但不是全部贪心的统一前提。
