#  欧拉函数

1. **定义**

    `φ(n)` 表示 `1 ~ n` 中与 `n` 互质的整数个数，规定 `φ(1) = 1`。

    $$
    \varphi(n)=\sum_{i=1}^{n}[\gcd(i,n)=1]
    $$

2. **计算公式**

    按不同质因子依次扣除其倍数。

    $$
    \varphi(n)=n\prod_{p\mid n}\left(1-\frac1p\right)
    $$

    每个质因子只计算一次。单次更新为：

    ```cpp
    ans = ans / p * (p - 1);  // 先除后乘，避免中间乘积溢出
    ```

3. **单个求值：初始化**

    保留答案，用 `x` 分解质因子。以下要求 `n ≥ 1`。

    ```cpp
    long long x = n, ans = n;
    ```

4. **枚举质因子**

    发现因子后更新答案，再除尽该因子，避免重复计算。

    ```cpp
    for (long long p = 2; p <= x / p; ++p) {
        if (x % p != 0) continue;
        ans = ans / p * (p - 1);
        while (x % p == 0) x /= p;
    }
    ```

    用 `p <= x / p` 代替 `p * p <= x`，避免乘法溢出。

5. **处理剩余质因子**

    循环结束后，若 `x > 1`，则 `x` 是剩余的质因子。

    ```cpp
    if (x > 1) ans = ans / x * (x - 1);
    ```

    最终 `ans = φ(n)`。时间为 `O(√n)`，辅助空间为 `O(1)`。

6. **线性筛**

    求 `1 ~ N` 的欧拉函数。每个合数只由最小质因子筛一次。

    先初始化数组和质数表：

    ```cpp
    vector<int> phi(N + 1), primes;
    vector<bool> composite(N + 1, false);
    phi[1] = 1;  // 要求 N ≥ 1
    ```

    从小到大枚举 `i = 2 ~ N`。未被筛过的数是质数：

    ```cpp
    if (!composite[i]) {
        primes.push_back(i);
        phi[i] = i - 1;
    }
    ```

    在每个 `i` 内，按升序枚举质数 `p`：

    ```cpp
    for (int p : primes) {
        if (p > N / i) break;  // 保证 i * p 不越界
        composite[i * p] = true;
        if (i % p == 0) {
            phi[i * p] = phi[i] * p;
            break;            // 保证由最小质因子筛出
        }
        phi[i * p] = phi[i] * (p - 1);
    }
    ```

    - `p | i`：没有新增质因子，`φ(ip) = pφ(i)`。
    - `p ∤ i`：新增质因子 `p`，`φ(ip) = (p - 1)φ(i)`。

    时间为 `O(N)`，空间为 `O(N)`。

7. **常用性质**

    **质数与质数幂：** `p` 为质数，`k ≥ 1`。

    $$
    \varphi(p)=p-1,\qquad \varphi(p^k)=p^{k-1}(p-1)
    $$

    **积性：** 仅当 `gcd(a, b) = 1` 时，可直接拆成乘积。

    $$
    \varphi(ab)=\varphi(a)\varphi(b)
    $$

    **约数求和：** 对所有正整数 `n` 成立。

    $$
    \sum_{d\mid n}\varphi(d)=n
    $$

    **欧拉定理：** 要求 `gcd(a, m) = 1`。

    $$
    a^{\varphi(m)}\equiv 1\pmod m
    $$

    互质时，非负指数可对 `φ(m)` 取模；不互质时不能直接套用。
