## **模运算的部分性质:**


$(a+b)\bmod n=(a\bmod n+b\bmod n)\bmod n$

$(a-b)\bmod n=(a\bmod n-b\bmod n+n)\bmod n$

$(a\cdot b)\bmod n=((a\bmod n)\cdot (b\bmod n))\bmod n$

$a^b\bmod n=(a\bmod n)^b\bmod n$

$a\ mod\ b=a\ −\ b·⌊a/b⌋$

## 同余

设整数 $m\ge1$（称为**模**，modulus），$a,b\in\mathbb Z$。

若 $m\mid(a-b)$，则称 $a$ 与 $b$ **模 $m$ 同余**，记作 $$a\equiv b\pmod m .$$

同余号 $\equiv$ 可以视为"模 p 意义下的等于"，加、减、乘性质都与普通等号一致(乘法运算时不可直接消去两侧相同因子，需要因子与 mod 互质)，除法需除数 x 与模数 p 互质时才可进行

## 求解逆元：

> ### 逆元是什么：
>
> 根据前面已经给出的性质，我们知道加、乘可以直接在计算时取模
>
> 但是除法不可直接取模：
>
> eg：取模 5 时，$5≡0(mod5)$ ，但$5/5=1,0/0$ 无定义
>
> 根据除法是乘法的逆运算,我们要找到一个数,使得其能“抵消”乘法的影响,这就是**倒数**。
>
> 就是构造出 $\frac1a$ ,使得 $a∗\frac1a=1$ ,然后乘以 $\frac 1a$ 这个操作就等价于除以 a
>
> 类似地,我们可以定义定义同余系内的**乘法逆元(倒数) **$a^{−1}$ 是 : 满足 $ab=1\ (mod\ p) $ 的 b
>
> 根据这个同余系的定义,这个 $a^{−1}$  是整数。没错,不是分数是**整数**。
>
> 这就是同余系的魅力,无论在经典数系里面怎样的复杂,只要能在同余系中表示,就一定是整数。
> $$
> a/b\ (mod \ p) \ =>a*b^{-1} (mod\ p)
> $$

## **费马小定理 **(Fermat's Little Theorem)


> 若 $p$ 为质数，整数 $a$ 与 $p$ 互质，则 $a^{p-1}\equiv 1\pmod p$
>
> 另一种形式：对于任意整数 $a$，有 $a^p\equiv a\pmod p$

由以上定理：

$a^{p-1}\equiv 1\pmod p$

左边提出一个 $a$：

$a\cdot a^{p-2}\equiv 1\pmod p$

因此可得出：

$a^{-1}\equiv a^{p-2}\pmod p$

因此 $a$ 关于模 $p$ 的逆元就是 **$a^{p-2}\bmod p$。**

例如要求 $(15/5)\bmod 4$，就先求 $5$ 关于 $4$ 的逆元 $5^{4-2}\bmod 4=25\bmod 4=1$，然后就可以转化为 $(15/5)\bmod 4=(15\cdot 1)\bmod 4=3$

**条件**：a 和 p 互质 + **p 为质数**才可使用费马小定理计算逆元，仅 a 和 p 互质需要使用[扩展欧几里得算法](https://io.zouht.com/67.html)求逆元。

> 学习扩展欧几里得的预备知识：
>
> #### **裴蜀定理 (Bézout's lemma)**
>
> 对任何整数 $a$、$b$ 和 $m$，关于未知数 $x$ 和 $y$ 的线性丢番图方程（称为裴蜀等式）：
>
> $$
> ax+by=m
> $$
> 当且仅当 $m$ 是 $a$ 及 $b$ 的最大公约数 $d$ 的倍数时有解 ($m|gcd(a,b)$)
>
> #### 这玩意和逆元有什么关系呢?
>
> 注意到,当 $gcd⁡(a,b)=1$ 的时候,方程变为 $ax+by=1$
>
> 等式两边模 b 得到 : $ax=1\ (mod\ p)$
>
> 这正是逆元的定义式!
>
> 而且根据斐蜀定理，$gcd(a,b)>1$ 时这个方程无解。
>
> 否则 $gcd(a,b)=1$ ,此时求出的 $x$ 就是 $a−1$

## 扩展欧几里得算法 (Extended Euclidean algorithm)

**算法描述:**

已知整数 $a$、$b$，扩展欧几里得算法可以在求得 $a$、$b$ 的最大公约数的同时，能找到整数 $x$、$y$（其中一个很可能是负数），使它们满足**贝祖等式**：
$$
ax + by = \gcd(a, b)
$$

> 换成人话就是裴蜀定理中的 m 可以换成 $gcd(a,b)$ ，通过推导就可以获得一组解 x ,y 另加 gcd(a,b)

**算法过程:**

前置：辗转相除法 $gcd(a,b)=gcd(b,a \% b)$

对于式子：
$$
ax\ + \ by\ =gcd(a,b)
$$
令 $a_2=b$ 、$b_2=a\%b$

根据辗转相除法可得： $gcd(a , b)=gcd(a_2 , b_2)$

假设 $x_2$ 、 $y_2$ 已知，原式：
$$
a_2x_2\ + \ b_2y_2\ =\ gcd(a,b)
$$
将 $a_2$ 、 $b_2$ 带回原式：
$$
bx_2\ + \ (a\%b)y_2 =gcd(a,b)  \\
= bx_2\ + \ (a-b \lfloor {\frac a b}\rfloor)y_2 =gcd(a,b)
$$
使用类似于选主元的思想，将公式化为：
$$
ay_2\ +\ b(x_2-\lfloor\frac a b\rfloor y_2)=gcd(a,b)
$$
对比原式 $ax+by=gcd(a,b)$ ,可以对应取值：
$$
x=y_2\ ,\ y=(x_2-\lfloor \frac a b\rfloor y_2)
$$
故知道 $ay_2\ +\ b(x_2-\lfloor\frac a b\rfloor y_2)=gcd(a,a\%b)的解$ $x_2$ 、$y_2$  时即可$O(1)$ 求解 $ax\ + \ by\ =gcd(a,b)$ 

 $x$ 、$y$ 

这个过程是嵌套的，也就是说，可以按照$x\ 、 x_2\ 、x_3\dots$一直向下递归

这个递归的出口为: 当 $ b=0$ 时 ， $gcd(a,0)=a$ ，

此时 $ax=a$ , 即 $x=1$ ,一定有解 $x=1$ 、 $y=0$

所以向前回溯，就可以解出 $x_n,y_n$ 、 $x_{n-1},y_{n-1}$ 、 $\dots$ 、$x_2,y_2$ 直到最终解 $x,y$

代码：

```cpp
ll exgcd(ll a,ll b,ll& x,ll& y){
    if(!b){
        x=1;
        y=0;
        return a;
    }
    ll d=exgcd(b,a%b,y,x);
    y-=a/b*x;
    return d;
}
```

注意这里递归传值是交叉的

原因是由上述推导可知: $x=y_2,y=x_2-\lfloor \frac a b\rfloor y_2$ 提前交换对应 x,y 值可以省下回溯时的显式赋值与交换

**通解**：

通过以上方法求解一对整数特解 $(x_0,y_0)$：
$$
ax_0+by_0=gcd(a,b)
$$
有：
$$
a\frac {cx_0} {gcd(a,b)}+b\frac {cy_0}{gcd(a,b)}=c
$$
此时获得第二对整数特解 $(x_1,y_1)$ :
$$
x_1=\frac {cx_0} {gcd(a,b)},y_1=\frac {cy_0}{gcd(a,b)}
$$
构造通解：令参数 $d\in Q$ 
$$
a(x_1+db)+b(y_1-da)=c
$$

> 约束：$x_1+db$ , $y_1-da$ 必为整数

规定变化量： $d_x=db$ 、 $d_y=da$ 表示解相对于$x_1$ 、$y_1$ 的变化量

 归约后可得： $d=\frac {d_x}b=\frac {d_y}a$ 即两者总积恒定 ，一边减少另一边一定增加



最小时 $d_x=\frac b{gcd(a,b)}$ ， $d_y=\frac a {gcd(a,b)}$*，在*$d=\frac 1 {gcd(a,b)}$ 时取到

即可得通解：
$$
x\ =\ x_1+sd_x \\
y\ = \ y_1-sd_y
$$
其中 $s$ 为任意整数

由于 x,y 要求为整数，所以 d 一定是 $\frac1{gcd(a,b)}$ 的倍数

将 $d_x、d_y$ 拆开，可得：
$$
x\ =\ x_1+\frac{s·b}{gcd(a,b)} \\
y\ = \ y_1-\frac{s·a}{gcd(a,b)}
$$
即寻找 x、y 目标值时，应递增/减 $\frac b{gcd(a,b)}$ / $\frac a{gcd(a,b)}$ 直到获取自己需要的值

eg:[P5656 【模板】二元一次不定方程 (exgcd)](https://www.luogu.com.cn/problem/P5656)

这道题目几乎已经覆盖了 exgcd 的所有常用解法

包括求是否有解、求 x,y 最大值/最小值 、 求合法正整数解个数

比较需要注意的是:

- 模数问题(无正整数解时应该模 $d_x/d_y$ : $x\equiv x_1\ mod\ d_x$) 

- 大规模的上/下取整

- x、y最值系数 s 为上下界 $[\ \lfloor\frac {1-x_1}{d_x}\rfloor,\lceil\frac {y_1-1}{d_y}\rceil\ ]$ 而非 1 

变量很绕，建议配合上方的推导手算一遍

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

ll exgcd(ll a,ll b,ll& x,ll& y){	//扩展欧几里得求ax+by=gcd(a,b)的解
    if(!b){
        x=1;
        y=0;
        return a;
    }
    ll d=exgcd(b,a%b,y,x);	//注意要反向传值
    y-=a/b*x;
    return d;
}

void solve(){
    ll a,b,c;
    cin>>a>>b>>c;
    ll x0=0,y0=0,d=exgcd(a,b,x0,y0);	//x0,y0,d=gcd(a,b)
    if(c%d){	//c 不为 gcd(a,b)的倍数，由裴蜀定理直接判无解
        cout<<-1<<'\n';
        return;
    }
    x0=x0*c/d,y0=y0*c/d;	//注意，此时的 x0,y0 值已经改为了 x1,y1
    ll dx=b/d,dy=a/d,L=ceil((double)(1-x0)/dx),R=floor((double)(y0-1)/dy),xmin=(x0%dx+dx)%dx,ymin=(y0%dy+dy)%dy;
    //从左到右: dx,dy,s左边界，s右边界，无正整数解时最小正整数 xmin,ymin,为什么模dx/dy原因见上
    if(R<L){ 	//左界大于右界 无正整数解
        cout<<(xmin==0? dx:xmin)<<' '<<(ymin==0? dy:ymin)<<'\n';
        return;
    }else{	//有正整数解
        xmin=x0+dx*L,ymin=y0-dy*R;		//最小/最大正整数 x,y 值，根据 s 边界求最值
        ll xmax=x0+dx*R,ymax=y0-dy*L;
        cout<<(xmax-xmin)/dx+1<<' '<<xmin<<' '<<ymin<<' '<<xmax<<' '<<ymax<<'\n';
        //注：这里统计需要+1,因为计算的是范围内解的个数，其中至少有一个数
    }
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```



**代码实现:**

代码中，返回值并未用三元组，而是返回最大公约数，同时通过引用传回了 $x$ 和 $y$，没有本质区别。

```cpp
int exgcd(int a, int b, int &x, int &y){
    if (!b){
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b, a % b, y, x);
    y -= a / b * x;		////y=x_2-a/b*y_2 当前x=y_2,y=x_2
    return d;
}
```

另一种写法：

```cpp
int exgcd(int a, int b, int &x, int &y){
    if (!b){
        x = 1;
        y = 0;
        return a;
    }
    int d = exgcd(b, a % b, x, y);	//正向传入，回溯时手动交换 x y 值
    int t = x;		//此时 x = x_2 , y = y_2 ,显式记录 x 并交换
    x = y;
    y = t - a / b * y;
    return d;
}
```



#### 解决模数非质数的乘法逆元：


当 $p$ 为质数时，可使用费马小定理求出乘法逆元：
$$
a^{-1}\equiv a^{p-2}\pmod p
$$

```cpp
ll invFermat(ll a) { return qpow(a, MOD - 2); }
```



但当 $p$ 非质数时，该方法失效。此时可构造线性同余方程：
$$
ax\equiv1\pmod p
$$
再使用上一节的方法，利用扩展欧几里得算法解该方程即可，代码如下：

```cpp
int inv(int a, int p){
    int x, y;
    if (exgcd(a, p, x, y) != 1)
        return -1; // 无解
    return (x % p + p) % p;
}
```

注意无解的情况，由裴蜀定理的约束条件，$a$ 和 $x$ 必须满足 $\gcd(a,p)=1$ 才有解。

**即：数 $a$ 与模数 $p$ 不互质时，$a$ 对于 $p$ 没有乘法逆元。**

#### 求 $1$ ~ $n$ 的连续逆元：

现在已知 $1$ ~ $n-1$ 的逆元，要求解 $n^{-1}$ 

将 $p$ 分解为 $p=k*i+r$ 

可得 $k=\lfloor\frac p i\rfloor$ , $r=p \ mod\  i$

将该式子置于 $mod\ p$ 环境下，可得： $k*i+r\equiv0\ (mod \ p)$

向等式两侧同乘 $i^{-1}$ 、 $r^{-1}$ ：

$k*r^{-1}+i^{-1}\equiv0\ (mod \ p)$

$i^{-1}\equiv-k*r^{-1}\ (mod\ p)$

将上方 $k$ 、 $r$ 带回：

$i^{-1}\equiv -\lfloor\frac p i\rfloor*(p\ mod\ i)^{-1}\ (mod\ p)$

由于任何整数加上模数 $p$ 后与模数 $p$ 同余，所以：

$p-k-(-k)=p$

而由 $p\equiv0\ (mod\ p)$可得:

$-k\equiv p-k\ (mod\ p)$

带回可得：

$i^{-1}\equiv (p-k)*r^{-1}\ (mod\ p)$

即： $i^{-1}\equiv (p-\lfloor \frac p i\rfloor)*(p\ mod\ i)^{-1}\ (mod\ p)$

这种写法没有负数，更好使用代码表示

```cpp
void buildInv(int n) {
    inv[1] = 1;
    for (int i = 2; i <= n; i++)
        inv[i] = (p - p / i) * inv[p % i] % p;
}
```

#### 阶乘递推逆元：

设 $fac[n]=n!\ (mod\ p)$ , $ifac[n]=(n!)^{-1}\ (mod\ p)$ 

则 $n^{-1} =\frac{(n-1)!}{n!}=fac[n-1]*ifac[n]$

可得
$$
\begin{cases}
n!=(n-1)!*n \\
\frac 1{n!}=\frac1 {(n+1)!}*(n+1)
\end{cases}
$$
即 $fac[i]=fac[i-1]*i$ ,$ifac[i-1]=ifac[i]*i$

```cpp
fac[0]=1;
for(int i = 1; i <= n + 1; i++) fac[i] = fac[i-1] * i % mod;//多求一项，也可以单独求fac[n]
//ifac[n]=qpow(ifac[n],mod-2)
for(int i = n + 1; i >= 1; i--) ifac[i-1] = ifac[i] * i % mod;
```

这个式子可以推广到任意正整数序列：

给定 $n$ 个连续的正整数 $a_i$

设前 i 个数前缀积为 $S[i]$ , 前缀积逆为 $inv[i]$

观察阶乘法公式： $n^{-1} =\frac{(n-1)!}{n!}=fac[n-1]*ifac[n]$ 

可知其本质是数列 $a_1=1、a_2=2、a_3=3\dots$ 的逐项逆元

所以拓展公式至 $a_i$ 为任意整数：
$$
(a[n])^{-1}=S[n-1]*inv[n]
$$
eg:[P5431 【模板】模意义下的乘法逆元2](https://www.luogu.com.cn/problem/P5431) 

这个公式的模板题,其实有不少坑

应对照阶乘逆元公式先求前缀积逆元，再由上述公式求解每个数的逆元

另外对照阶乘法求逆元 $ifac[i-1] = ifac[i] * i % mod;$ 中，每项递推乘以了 i 

这是因为阶乘每一项原本值与 i 对应 ， 此处应该乘以对应原数据

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

ll fast_p(ll a,ll b,ll mod){	//快速幂
    ll ans=1;
    while(b){
        if(b&1) ans=ans*a%mod;
        a=a*a%mod;
        b>>=1;
    }
    return ans;
}

void solve(){
    ll n,p,k;
    cin>>n>>p>>k;
    ll v[n+1],pre[n+1],inv[n+1],ans=0,ki=k;	//原数组、前缀积、前缀积逆元、答案、每项k累计
    pre[0]=1;
    for(int i=1;i<=n;i++){
        cin>>v[i];
        pre[i]=pre[i-1]*v[i]%p;
    }
    inv[n]=fast_p(pre[n],p-2,p);	//费马小定理单项求逆元
    for(int i=n;i>0;i--){
        inv[i-1]=inv[i]*v[i]%p;	//反向递推，注意乘的是原数据 v[i]
    }
    for(int i=1;i<=n;i++){
        ans=(ans+ki*pre[i-1]%p*inv[i])%p;	//每步求逆元累加
        ki=ki*k%p;
    }
    cout<<ans<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    // cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
