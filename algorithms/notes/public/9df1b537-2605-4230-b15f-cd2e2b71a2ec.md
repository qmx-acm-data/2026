# 素（质）数筛

## 一、引入：试除法



如果 $x$ 是合数，就能写成 $x=a\cdot b$，其中 $2\le a\le b$。由 $a^2\le ab=x$ 可知 $a\le\sqrt{x}$，所以从 $2$ 试除到 $\lfloor\sqrt{x}\rfloor$ 就够了。循环条件要包含等号，例如判断 $49$ 时需要试到 $7$。

**板子如下：**

```cpp
bool isprime(int x){
    if(x < 2)return false;
    for(int i = 2; 1ll*i*i <= x; i++){ // 1ll 表示long long 类型的整数 1
        if(x % i == 0)return false;
    }
    return true;
}
```

注：`1ll*i*i` 用 `long long` 做乘法，防止 `int` 溢出。

- 判断一个整数 $x\ge2$，最坏时间 $O(\sqrt{x})$，额外空间 $O(1)$。

- 逐个判断 $1$ 到 $N$ **这 $N$ 个整数** 时，即时间复杂度为 $O(N\sqrt N)$ 。

- 适合只判断 **一个** 或 **少量** 数，**而且试到平方根的开销可以接受的题目**。



### 试除优化：$6k\pm1$

重要：**此内容了解即可。（首次学习可忽略）**

大于 $3$ 的质数模 $6$ 只可能余 $1$ 或 $5$。余 $0,2,4$ 的数能被 $2$ 整除，余 $3$ 的数能被 $3$ 整除。先处理 $2$ 和 $3$，后续只需要试除 $5,7,11,13,\dots$。例如 $25$ 也形如 $6k+1$，仍需做整除检查。这个优化减少了取模次数，最坏时间仍为 $O(\sqrt{x})$。


## 二、埃氏筛

从 $2$ 开始从小到大枚举。若 $i$ 还没有被标记，就把它加入质数表，再划掉 $2i,3i,4i,\dots,ki $ 。

注：

1.  别把 $i$ 给划了。

2. $ki$ 小于 $N$ 。

原因：**任意合数** 都有一个 **比自身小的质因子** ，所以在枚举到这个合数之前，至少会被划掉一次。

**板子如下：**

```cpp
const int N = 1e8+1; // 可按题目调整的上限
vector<int> prime;
bool isprime[N]; // 表示是否是质数，筛完后用 isprime[x] 判素数

void sieve(int n){ // 预处理 [0,n]，要求 0<=n<=N
    
    memset(isprime, true, sizeof(isprime));//初始化都符合，因为一个也没被划掉
    isprime[0] = isprime[1] = false; // 0 与 1 肯定不是质数（注意边界）

    for(int i = 2; i <= n; i++){
        if(isprime[i]){ 
            for(int k = 2; 1ll*k*i <= n; k++){//优化: k 从 i 开始
                isprime[k*i] = false;// 直接划掉
            }
            prime.push_back(i);
        }
    }
}
```

- 利用   $C++STL$ 的 $bitset$ 代替 $bool$ ，内存开销直接降 $8$ 倍。

- 预处理时间 $O(n\log\log n)$。

- 固定数组按上限 $N$ 分配，空间 $O(N)$。**这里注意 `bool` 数组，在 $N$ 很大的时候能够保证不浪费空间**。

- 筛完后（也就是**预处理**结束），对 $0\le x\le n$，用 `!isprime[x]` 可以在 $O(1)$ 时间内判素。

- 进一步优化：内层可以从 `k=i` 开始，即从 $i^2$ 划。对于 $2\le j<i$，$ij$ 含有小于 $i$ 的质因子，**肯定已经被标记过了**。

### 拓展：区间筛

当 $R$ 很大，却只需要筛一段较短的 $[L,R]$ 时，可以把**埃氏筛**用在这段**区间**上。

先筛出 $1$ 到 $N$ 的质数，其实可以去筛到 $N^2$ 的短区间，这个**原理**在前面的从 $i^2$ 的优化 一样的。

例如，筛 $[10^{12},10^{12}+10^5]$，只需筛到约 $10^6$ 找**小质数**，再给目标区间开 $100001$ 个标记位。区间内任意合数 $x$ 都有一个质因子 $p\le\sqrt{x}\le\sqrt R$，用这些小质数就能划掉所有合数。

跟上面的埃氏筛一样，枚举质数 $p$ 的倍数 `k*p`。这次 `k` 要从 $\max(p,\lceil L/p\rceil)$ 开始，保证 `k*p` 既不小于 $p^2$，也不小于 $L$。用 `isprime[x-L]` 对应原数 $x$，其中 `1` 表示已排除。比如筛 $[100,120]$ 时，$p=7$ 从 $105$ 开始，依次划掉 $105,112,119$。

**板子如下：**

```cpp
vector<bool> segmentSieve(long long L,long long R){ // 要求 0<=L<=R，且两张表能放下
    long long s = sqrtl(R);
    while(s+1 <= R/(s+1)) s++;
    while(s > 0 && s > R/s) s--; // 修正浮点误差，得到 floor(sqrt(R))

    vector<bool> small_prime(s+1,true);     // 先筛到 s，用来找小质数
    vector<bool> isprime(R-L+1,true); // [L,R] 的标记表

    //处理边界
    if(L == 0) isprime[0] = false;
    if(L <= 1 && R >= 1) isprime[1-L] = false;

    for(long long p = 2; p <= s; p++){
        if(small_prime[p]){
            for(long long x = p*p; x <= s; x += p){
                small_prime[x] = false;
            }
            long long first = max(p, L/p+(L%p!=0));
            long long last = R/p;
            for(long long k = first; k <= last; k++){
                isprime[k*p-L] = false;
            }
        }
    }
    return isprime;
}
```

`L/p+(L%p!=0)` 是向上取整（小trick）。`k<=R/p` 保证乘出 `k*p` 时仍在范围内。筛完后，用 `!isprime[x-L]` 判素。要列出所有质数，从左到右扫一遍标记表即可。

- 设 $S=\lfloor\sqrt R\rfloor$，$W=R-L+1$。筛小质数需要 $O(S\log\log S)$ 时间。每个小质数 $p$ 在目标区间里最多标记 $W/p+1$ 次，累加后总时间为 $O((S+W)\log\log R)$（按 $R$ 较大时计）。

- 空间为 $O(S+W)$，筛完后单次判素为 $O(1)$。适合 $W$ 较小，而且筛到 $S$ 的时间和空间开销都能接受的题目。

## 三、线性筛/欧式筛

欧拉筛**预处理**到 $n$ 需要 $O(n)$ 时间和 $O(n)$ 空间，预处理后单次判素为 $O(1)$。

需要**反复分解** $[2,n]$ 内的数时，可以在线性筛中另外记录每个数的**最小质因子**。分解 $x$ 时，每轮取出一个最小质因子并除掉它，最多做 $O(\log x)$ 轮。

### 前置：算术基本定理（唯一分解定理）


任何一个大于 $1$ 的自然数 $N$，如果 $N$ 不为质数，那么 $N$ 可以唯一分解成有限个质数的乘积 $N=P_1^{a_1}P_2^{a_2}P_3^{a_3}\cdots P_n^{a_n}$，$P_1<P_2<P_3<\cdots<P_n$ 且均为质数，$a_1,a_2,a_3,\cdots,a_n$ 均为正整数。

> #### 定理推论
>
> - 一个大于 $1$ 的整数 $N$，如果它的标准分解式为 $N=P_1^{a_1}P_2^{a_2}P_3^{a_3}\cdots P_n^{a_n}$，那么它的正因数个数为 $\sigma_0(N)=(1+a_1)(1+a_2)\cdots(1+a_n)$
>
> #### **简单证明：**
>
> $P_1^{b_1}P_2^{b_2}P_3^{b_3}\cdots P_n^{b_n}\ (0\leq b_1\leq a_1,0\leq b_2\leq a_2,\cdots)$ 一定是 $N$ 的正因数。其中 $b_1$ 可选 $[0,a_1]$ 共 $1+a_1$ 种，$b_2$ 可选 $[0,a_2]$ 共 $1+a_2$ 种 $\cdots\cdots$
>
> 根据乘法原理，整体选法总数为：$(1+a_1)(1+a_2)\cdots(1+a_n)$。每一种选法对应一个正因数，则选法数量就是正因数的个数。
>
> - 它的全体正因数之和为 $\sigma_1(N)=(P_1^0+P_1^1+P_1^2+\cdots+P_1^{a_1})(P_2^0+P_2^1+P_2^2+\cdots+P_2^{a_2})\cdots(P_n^0+P_n^1+P_n^2+\cdots+P_n^{a_n})$
>
> #### **简单证明：**
>
> 我们将 $(P_1^0+P_1^1+P_1^2+\cdots+P_1^{a_1})(P_2^0+P_2^1+P_2^2+\cdots+P_2^{a_2})\cdots(P_n^0+P_n^1+P_n^2+\cdots+P_n^{a_n})$ 使用分配律展开，会得到一个多项式。
>
> 多项式中每个单项式的结构均为 $P_1^{b_1}P_2^{b_2}P_3^{b_3}\cdots P_n^{b_n}\ (0\leq b_1\leq a_1,0\leq b_2\leq a_2,\cdots)$，即 $N$ 的一个正因数。多项式的值便是所有正因数的和。

### 欧拉筛/线性筛：


基于**埃氏筛优化**(?) 我说本质都是**划掉合数**。

相比于埃氏筛每个合数**仅用**最小质因数`p`划去**一次**

**时间复杂度**远优于埃氏筛，但更绕的代码结构+更大的常数数据使其运行速度反而较埃氏筛持平/更慢

**核心思想：**

线性筛（欧拉筛）的核心想法：**将每个合数的最小质因子指定为唯一的负责人**.

让"$p$ 划掉 $p \cdot i$"这件事当且仅当 $p = \operatorname{spf}(p\cdot i)$ (意思是 $p$ 为 $p*i$ 的最小质因数) 时发生。代码里 `if (i % p == 0) break;` 就是此思想的体现：

- 内层质数 $p$ 从小到大枚举。只要 $i \% p \ne 0$，说明 $i$ 不含质因子 $p$，于是 $p$ 有资格当 $p\cdot i$ 的最小质因子；
- 一旦 $i \% p = 0$，说明 $p$ 已经出现在 $i$ 的质因数里，那么对于后面更大的质数 $q > p$，($q \cdot i$ )的最小质因数是 $p$（因为 $p \mid i$ 则 $p \mid q\cdot i$，且 $p < q$），**轮不到 $q$ 来负责**。既然 $q\cdot i$ 将来会由 $p$ 在另一个外层位置负责，现在就应当 `break`，避免重复。

**板子如下：**

```cpp
const int N = 1e8+1;
vector<int> prime;
bool isprime[N];

void sieve(int n){ // 依旧预处理，筛 [0,n]，要求 0<=n<=N
    
    isprime[0] = isprime[1] = false;

    for(int i = 2; i <= n; i++){
        if(isprime[i]) prime.push_back(i);
        for(int p:prime){
            if(1ll*i*p > n) break;
            isprime[i*p] = false;
            if(i%p == 0) break;
        }
    }
}
```

### 副产物一：最小质因子 `spf`

空间够时，可以把 `bool isprime[N]` 换成 `int spf[N]`。

`spf[i]` 记录 $i$ 的最小质因子，其中初值 `0` 表示还没被筛到。

枚举到这样的 $i$ 时，它是质数，令 `spf[i]=i`。筛掉 `i*p` 时，直接记下 `spf[i*p]=p`，因为欧拉筛恰好用最小质因子 $p$ 标记这个合数。

```cpp
// 沿用上面的 N 和 prime，并替换 isprime 数组
int spf[N];// isprime -> spf

void sieve(int n){ // 筛 [0,n]，要求 0<=n<N

    // 这次 0 与 1 的值就是 0，因为不存在

    for(int i = 2; i <= n; i++){
        if(spf[i] == 0){
            spf[i] = i;
            prime.push_back(i);
        }
        for(int p : prime){
            if(1ll*i*p > n) break;
            spf[i*p] = p;
            if(p == spf[i]) break;
        }
    }
}
```

内层的 `p==spf[i]` 等价于原板子在此处的 `i%p==0`，因为质数从小到大枚举，遇到第一个能整除 $i$ 的质数就会退出。筛完后，对 $2\le i\le n$，用 `i==spf[i]` 即可在 $O(1)$ 时间内判素。分解质因数时，每轮取 `spf[x]` 并令 `x/=spf[x]`，直到 `x==1`。例如 $12$ 依次取出 $2,2,3$。

### 副产物二：欧拉函数 `phi`

$\varphi(x)$ 表示 $1$ 到 $x$ 中与 $x$ 互质的整数个数。初值为 $\varphi(1)=1$。如果 $i$ 是质数，那么 $\varphi(i)=i-1$。筛到合数 $i\cdot p$ 时分两种情况：

- **$p$ 整除 $i$**。乘上 $p$ 后，质因子种类不变，$\varphi(i\cdot p)=\varphi(i)\cdot p$。算完这个值再 `break`。
- **$p$ 不整除 $i$**。此时 $i$ 和 $p$ 互质，由欧拉函数的积性，$\varphi(i\cdot p)=\varphi(i)\cdot\varphi(p)=\varphi(i)\cdot(p-1)$。

例如 $\varphi(12)=\varphi(6)\cdot2=4$，而 $\varphi(15)=\varphi(5)\cdot(3-1)=8$。

```cpp
// 沿用 N、prime 和 spf，在上一个板子上加 phi 数组
int phi[N];

void sieve(int n){ // 筛 [0,n]，要求 0<=n<N

    phi[1] = 1;

    for(int i = 2; i <= n; i++){
        if(spf[i] == 0){
            spf[i] = i;
            prime.push_back(i);
            phi[i] = i-1;
        }
        for(int p : prime){
            if(1ll*i*p > n) break;
            spf[i*p] = p;
            if(p == spf[i]){
                phi[i*p] = phi[i]*p;
                break;
            }
            phi[i*p] = phi[i]*(p-1);
        }
    }
}
```

**注意空间：**

每个合数仍只处理一次，预处理时间为 $O(n)$。筛完后，查 `spf[i]` 或 `phi[i]` 都是 $O(1)$。两个表按上限 $N$ 分配，空间为 $O(N)$。按 4 字节 `int` 算，每张表约占 $4N$ 字节，开到 $10^8$ 时每张约占 400 MB。

### 最后总结上面的判素方法：

| 食用条件 | 相应判素工具 |
| --- | --- |
| 列出 $1$ 到 $n$ 的所有素数，或在这个范围内大量判素 | **埃氏筛** 好写也常用，只要不用到欧式筛的副产物，那就选这个就行 |
| 大量**分解** $1$ 到 $n$ 内的数，或需要**最小质因子** | **欧拉筛**，筛的时候可以记录**最小质因子**或**欧拉函数** |
| $R$ 很大，只需要筛一段较短的 $[L,R]$，且筛到 $\sqrt R$ 可行 | **区间筛** |
| 只判**一个**或**少量**整数 | 数值较小时**试除法**试除到 $\sqrt x$|

### 拓展：求因子/求阶乘贡献

#### 求因子

以[1952. 三除数](https://leetcode.cn/problems/three-divisors/)为例：

两种写法：

法一：目标数m必定可以拆出数$n*k(0<n<=k<\sqrt m)$

所以遍历1~$\sqrt m$,每遍历到一个n即可找到一个对应k，因数+2

但当n=k时计数会多记录一个因子(默认n,k不同为两个因子，但是n=k就只能是同一个)

所以分开判n,k是否为因数

```cpp
vector<int> divisors(int n) {
    vector<int> factors;
    for (int d = 1; d * d <= n; d++) {
        if (n % d == 0) {
            factors.push_back(d);
            if (d * d < n) {	//两数相同就不记第二遍
                factors.push_back(n / d);
            }
        }
    }
    return divisors;
}
```

法二：参考埃氏筛，打表并记录所有数的所有因子

```cpp
const int MN=1e4;
vector<int> factors[MN+1];
int init=[]{
    for(int i=1;i<=MN;i++){
        for(int j=i;j<=MN;j+=i){
            factors[j].push_back(i);
        }
    }
    return 0;
}();
```

#### 求阶乘贡献

给定 $n$ 与素数 $p$，求 $n!$ 中质因子 $p$ 的指数 $e_p(n!)$，即最大的 $e$ 使 $p^e \mid n!$。例：$10! = 3628800 = 2^8\cdot3^4\cdot5^2\cdot7$，故 $e_2(10!) = 8,\ e_3(10!) = 4,\ e_5(10!) = 2,\ e_7(10!) = 1$。

逐层"补一个 p"：

- 只看 $1$ 到 $n$ 中 $p$ 的倍数，共 $\lfloor n/p\rfloor$ 个，每个至少贡献 1 个 $p$：先记下 $\lfloor n/p\rfloor$。
- 但 $p^2$ 的倍数（共 $\lfloor n/p^2\rfloor$ 个）含 $p$ 的指数至少是 2，刚才只算了一次，**还差一个**，补上 $\lfloor n/p^2\rfloor$。
- 同理 $p^3$ 的倍数还差第三个 $p$，补 $\lfloor n/p^3\rfloor$；一直补下去。
- 当 $p^k > n$ 时 $\lfloor n/p^k\rfloor = 0$，累加自然停止。

结论：$e_p(n!) = \left\lfloor \dfrac{n}{p} \right\rfloor + \left\lfloor \dfrac{n}{p^2} \right\rfloor + \left\lfloor \dfrac{n}{p^3} \right\rfloor + \cdots = \sum_{k\ge 1}\left\lfloor \dfrac{n}{p^k} \right\rfloor$

> 推导过程：
>
> 下面来计算 n！的质因数分解中，质数 p的个数。
>
> - 在 $ [1,n] $中，有 $ \left\lfloor \frac{n}{p} \right\rfloor $个数可以被 p整除，其中又有 $ \left\lfloor \frac{n}{p^{2}} \right\rfloor $个数可以被 $ p^{2} $整除，所以恰好能被 p整除，但不能被 $ p^{2} $整除的数有 $ \left\lfloor \frac{n}{p} \right\rfloor -\left\lfloor \frac{n}{p^{2}} \right\rfloor $个。例如 [1,10]中，有3个数2，6，10恰好能被 p=2整除。
>
> - 在 $[1,n]$ 中，有 $\left\lfloor \frac{n}{p^2}\right\rfloor$ 个数可以被 $p^2$ 整除，其中又有 $\left\lfloor \frac{n}{p^3}\right\rfloor$ 个数可以被 $p^3$ 整除，所以恰好能被 $p^2$ 整除，但不能被 $p^3$ 整除的数有 $\left\lfloor \frac{n}{p^2}\right\rfloor - \left\lfloor \frac{n}{p^3}\right\rfloor$ 个。
>
> - 依此类推，[1,n]中恰好能被 $ p^{k-1} $整除，但不能被 $ p^{k} $整除的数有 $ \left\lfloor \frac{n}{p^{k}-1}\right\rfloor - $ $ \left\lfloor \frac{n}{p^{k}}\right\rfloor $个。
>
> - 设 $ p^{k}\leq n<p^{k+1} $ ，那么[1,n]中恰好能被 $ p^{k} $整除的数有 $ \left\lfloor \frac{n}{p^{k}}\right\rfloor $个。
>
> 继续讨论：
>
> - 恰好能被 p整除的数，有1个质因子 p，所以这些数一共有1 $ \left(\left\lfloor \frac{n}{p}\right\rfloor -\left\lfloor \frac{n}{p^{2}}\right\rfloor\right) $个 p。
>
> - 恰好能被 $ p^{2} $整除的数，有2个质因子 p，所以这些数一共有2. $ \left(\left\lfloor \frac{n}{p^{2}}\right\rfloor -\left\lfloor \frac{n}{p^{3}}\right\rfloor\right) $个 p。
>
> . ...
>
> • 恰好能被 $p^{k-1}$ 整除的数，有 $k-1$ 个质因子 $p$，所以这些数一共有 $(k-1)\cdot\left(\left\lfloor\frac{n}{p^{k-1}}\right\rfloor-\left\lfloor\frac{n}{p^k}\right\rfloor\right)$ 个 $p$。
>
> • 恰好能被 $p^k$ 整除的数，有 $k$ 个质因子 $p$，所以这些数一共有 $k\cdot\left\lfloor\frac{n}{p^k}\right\rfloor$ 个 $p$。
>
> 累加，即为 $n!$ 的质因数分解中质数 $p$ 的个数：
>
> $$1\cdot\left(\left\lfloor\frac{n}{p}\right\rfloor-\left\lfloor\frac{n}{p^2}\right\rfloor\right)+2\cdot\left(\left\lfloor\frac{n}{p^2}\right\rfloor-\left\lfloor\frac{n}{p^3}\right\rfloor\right)+\cdots+(k-1)\cdot\left(\left\lfloor\frac{n}{p^{k-1}}\right\rfloor-\left\lfloor\frac{n}{p^k}\right\rfloor\right)+k\cdot\left\lfloor\frac{n}{p^k}\right\rfloor$$
>
> 化简得
>
> $$\left\lfloor\frac{n}{p}\right\rfloor+\left\lfloor\frac{n}{p^2}\right\rfloor+\cdots+\left\lfloor\frac{n}{p^k}\right\rfloor$$
>
> 此外，有如下恒等式
>
> $$\left\lfloor\frac{n}{p^k}\right\rfloor=\left\lfloor\frac{n/p^{k-1}}{p}\right\rfloor=\left\lfloor\frac{\lfloor n/p^{k-1}\rfloor}{p}\right\rfloor$$

作用：求每个质因子在n！内的出现次数

```cpp
// 返回 n! 中质因子 p 的指数，p 必须是素数，O(log_p n)
long long e_p_factorial(long long n, long long p) {
    long long cnt = 0;
    while (n) {          // n 依次为 n/p, n/p^2, n/p^3, ...
        n /= p;          // 先除
        cnt += n;        // 再累加"除之后"的 n，不是除之前的
    }
    return cnt;
}
```

以[172. 阶乘后的零](https://leetcode.cn/problems/factorial-trailing-zeroes/)为例：

$10 = 2\times5$，一个末尾零需要一对 $(2,5)$。$n!$ 的分解里 2 与 5 的数量分别是 $e_2, e_5$，能配成的对数就是 $\text{zeros}(n!) = \min\big(e_2(n!),\ e_5(n!)\big)$。而 $e_2 \ge e_5$ 恒成立：对每个 $k$ 有 $2^k < 5^k$，故 $\lfloor n/2^k\rfloor \ge \lfloor n/5^k\rfloor$，逐项求和即得。因此

$\text{zeros}(n!) = e_5(n!) = \sum_{k \ge 1}\left\lfloor \dfrac{n}{5^k} \right\rfloor$

```cpp
class Solution {
public:
    int trailingZeroes(int n) {
        int ans = 0;
        while (n) {
            // 循环 k 次后，n 变成了 floor(n/5^k)
            n /= 5;
            ans += n;
        }
        return ans;
    }
};
```



## 四、(进阶)Miller-Rabin算法：

> 注：这一部分是很古早的笔记，大多使用AI生成，仅作参考不保证正确性

对于每一个奇素数n：

根据费马小定理：任意底数a(与n互斥):$a^{n-1} \equiv 1(mod\ n)$ ,而 $x_s = a^{2^s d} = a^{n-1}$，所以 $x_s = 1$

将幂n-1拆解为$n-1=2^s*d$的形式,建立平方链：$x_0=a^d \ mod \ n$        $x_1 =x_0^2\mod\ n$    ……

直至$x_{s-1}=x_{s-2}^2 \mod \ n$ ($x_s$已知并恒定为1)

**若 $n$ 是素数**，则对任意与 $n$ 互素的 $a$，下面两件事至少有一件成立：

- (A)$x_0 = a^d \equiv 1 \pmod n$；或者
- (B)序列 $x_0, x_1, \dots, x_{s-1}$ 中存在某一项等于 $-1$（即 $n-1$）。

**注**：这个判据的严格方向是：

`n 是素数  ⟹  (A) 或 (B) 成立`

这是必要条件，也就是它的逆否才给出确定结论：

    非[(A) 或 (B)]  ⟹  n 是合数      ✓ 这是确定的

而顺着方向推：

    (A) 或 (B) 成立  ⟹  n 是素数      ✗ 这不成立

因为存在强伪素数（strong pseudoprime）：合数 n 也能对某个底数 a 通过测试。最小的是 2047 = 23 × 89，它骗过底数 2。

所以单个底数通过只能得到：

    "n 可能是素数，或 n 是骗过 a 的强伪素数"

这正是"见证人"这个说法的来源：

    a 判 n 合数  →  a 是铁证，n 100% 合数，流程立刻结束
    a 判 n 素数  →  a 只是"没能作证"，n 仍有嫌疑，换下一个底数继续问

关于底数$a$:

竞赛中一般不会直接roll一组随机数，而是直接将已知的一段（连续质数)序列作为底数

以下为常用底数及其有效范围：

| ------------------------------------------------------ | ------------------------------------------------------------ |

| $\{2, 3, 5, 7\}$                                       | $n < 3\,215\,031\,751$（$3\,215\,031\,751$ 本身就是第一个反例，所以必须严格小于） |

> ### 关于Miller-Rabin算法的推导过程：
>
> ##### 前置：费马小定理与费马素性测试
>
> ######  费马小定理
>
> **若 $p$ 是素数，$a$ 是任意整数且 $p$ 不整除 $a$，则 $a^{p-1} \equiv 1 \pmod p$。**
>
> 一句直觉：$a, 2a, \dots, (p-1)a$ 模 $p$ 之后恰好是 $1, 2, \dots, p-1$ 的一个排列（因为 $p$ 是素数，$ia \equiv ja$ 能约掉 $a$）；把两边全部乘起来得到 $a^{p-1}(p-1)! \equiv (p-1)!$，再约掉 $(p-1)!$ 就是结论。
>
> **为什么它能判素**：如果 $n$ 真是素数，那么任何与 $n$ 互素的 $a$ 都必须满足 $a^{n-1} \equiv 1 \pmod n$。于是反过来——**只要找到一个 $a$ 让等式不成立，$n$ 就一定是合数**。这是单向的铁证。
>
> ###### 费马素性测试
>
> 拿几个底数 $a$ 逐个检验：
>
> ```cpp
> // 返回 true 表示"通过了 a 这一轮"
> bool fermat_round(unsigned long long n, unsigned long long a) {
> return pow_mod(a % n, n - 1, n) == 1;
> }
> ```
>
> 判定规则：
>
> - 所有底数都通过 → 报"大概率是素数"；
> - 只要有一个不通过 → 报"一定是合数"。
>
> 注意方向：**不通过 ⇒ 合数（确定）；通过 ⇏ 素数**。
>
> ######  致命缺陷：卡迈克尔数
>
> "通过"不等于"素数"，而且这个洞不是加几个底数能补的。存在这样一类合数 $n$：**对所有与 $n$ 互素的 $a$，都有 $a^{n-1} \equiv 1 \pmod n$**。它们叫卡迈克尔数（Carmichael number），又叫绝对费马伪素数。
>
> 最小的几个：
>
> ```
> 561, 1105, 1729, 2465, 2821, 6601, 8911, 10585, 15841, 29341, ...
> ```
>
> （判定它们的充要条件叫 Korselt 判据：$n$ 无平方因子，且对 $n$ 的每个素因子 $p$ 都有 $p - 1 \mid n - 1$。这里只用它理解"为什么这种数能骗过所有底数"，不展开证明。）
>
> 拿 561 做对比：
>
> | $n$  | 类型                           | 费马测试（$a = 2, 3, 5, 7, \dots$ 中所有与 $n$ 互素的 $a$） | 结果           |
> | ---- | ------------------------------ | ----------------------------------------------------------- | -------------- |
> | 561  | 合数 $= 3 \times 11 \times 17$ | 全部通过                                                    | **误判为素数** |
> | 1105 | 合数 $= 5 \times 13 \times 17$ | 全部通过                                                    | **误判为素数** |
> | 1729 | 合数 $= 7 \times 13 \times 19$ | 全部通过                                                    | **误判为素数** |
> | 15   | 合数                           | $2^{14} \bmod 15 = 4 \ne 1$，$a=2$ 就抓住                   | 正确判为合数   |
> | 341  | 合数 $= 11 \times 31$          | $a = 2$ 通过（伪素数），$a = 3$ 抓住                        | 正确判为合数   |
>
> 对 561 这类数，底数从 3 个加到 30 个也没用——**错误率是 1，不是"概率很小"**。费马测试需要结构性的加强，不是更多的底数。
>
> ---
>
> ##### 3. 关键的观察：二次探测定理
>
> ###### 3.1 定理
>
> **若 $p$ 是奇素数，且 $x^2 \equiv 1 \pmod p$，则 $x \equiv 1 \pmod p$ 或 $x \equiv -1 \pmod p$。**
>
> 推导只有两行：
>
> ```
> x^2 ≡ 1  ⟹  x^2 - 1 ≡ 0  ⟹  (x-1)(x+1) ≡ 0  (mod p)
> ```
>
> $p$ 是素数，所以"$p$ 整除一个乘积"必然"$p$ 整除其中一个因子"（素数的定义性质，欧几里得引理），于是 $p \mid (x-1)$ 或 $p \mid (x+1)$，即 $x \equiv \pm 1 \pmod p$。
>
> ###### 3.2 反过来用（真正有用的方向）
>
> > 如果在模 $n$ 下找到一个 $x$，满足 $x^2 \equiv 1 \pmod n$ 但 $x \not\equiv \pm 1 \pmod n$，那么 $n$ **一定是合数**。
>
> 理由就是定理的逆否命题：$n$ 若是素数，这种情况不可能出现。
>
> 还能顺手捞一个因子：此时 $n \mid (x-1)(x+1)$，而 $n$ 不整除 $x-1$、也不整除 $x+1$，所以 $\gcd(x-1, n)$ 是 $n$ 的非平凡因子（$1 < \gcd < n$）。第 4.2 节的 561 例子会看到这一点。
>
> ###### 3.3 为什么必须先把 $n-1$ 拆成 $2^s \cdot d$
>
> 定理只说"$x^2 \equiv 1 \Rightarrow x = \pm 1$"，可我们要检验的是 $a^{n-1} \equiv 1$，中间隔着一大串指数。**唯一能让"反复平方"和 $a^{n-1}$ 衔接起来的写法，就是把 $n-1$ 里所有因子 2 提干净**：
>
> ```
> n - 1 = 2^s · d        （d 为奇数）
> ```
>
> 这样 $a^{n-1} = \left(a^{d}\right)^{2^s}$：从 $a^d$ 出发连续平方 $s$ 次，正好落到 $a^{n-1}$。链上相邻两项严格满足"后一项是前一项的平方"，二次探测定理才有用武之地。$n$ 是大于 2 的奇数时 $n-1$ 是偶数，所以 $s \ge 1$。
>
> ---
>
> ##### 4. Miller-Rabin 的推导
>
> ###### 4.1 从素数出发，倒推一个"必须成立"的模式
>
> 设 $n$ 是奇素数，$a$ 与 $n$ 互素，$n - 1 = 2^s d$。定义平方链：
>
> ```
> x_0 = a^d mod n
> x_i = x_{i-1}^2 mod n        (1 ≤ i ≤ s)
> ```
>
> 逐步推：
>
> 1. 费马小定理给出 $a^{n-1} \equiv 1 \pmod n$，而 $x_s = a^{2^s d} = a^{n-1}$，所以 $x_s = 1$。
> 2. $x_s = x_{s-1}^2 = 1$，对 $x_{s-1}$ 用二次探测定理（$n$ 是素数）：$x_{s-1} \equiv \pm 1$。
> 3. 若 $x_{s-1} \equiv -1$：**这一轮就通过了**，不用再往回看——$(-1)^2 = 1$，后面的 $x_s$ 自然满足费马，链上再没有别的约束。
> 4. 若 $x_{s-1} \equiv 1$：对 $x_{s-2}$ 重复步骤 2（因为 $x_{s-1} = x_{s-2}^2$），得到 $x_{s-2} \equiv \pm 1$；是 $-1$ 就通过，是 $1$ 就继续往回退。
> 5. 一路退到 $x_0$ 退无可退：此时只要求 $x_0 = \pm 1$，而 $x_0 = 1$ 就是终点形态。
>
> 把回退过程收成结论，得到 Miller-Rabin 的判据：
>
> > **若 $n$ 是素数**，则对任意与 $n$ 互素的 $a$，下面两件事至少有一件成立：
> >
> > 1. $x_0 = a^d \equiv 1 \pmod n$；或者
> > 2. 序列 $x_0, x_1, \dots, x_{s-1}$ 中存在某一项等于 $-1$（即 $n-1$）。
>
> 逆否命题就是算法：**如果 $x_0 \ne 1$，且 $x_0, \dots, x_{s-1}$ 里一个 $-1$ 都没有，那么 $n$ 一定是合数。**
>
> 对应到代码：$x_0$ 单独判一次，剩下的 $x_1, \dots, x_{s-1}$ 由循环平方 $s-1$ 次逐个得到。
>
> ###### 4.2 具体例子：$n = 561$，$a = 2$
>
> 561 是卡迈克尔数，费马测试拿它没办法。看 Miller-Rabin 怎么撕开它：
>
> ```
> 560 = 2^4 · 35                  →  d = 35, s = 4
> 
> x_0 = 2^35  mod 561 = 263       （既不是 1，也不是 560）
> x_1 = 263^2 m24od 561 = 166
> x_2 = 166^2 mod 561 =  67
> x_3 =  67^2 mod 561 =   1       （不是 560）
> ```
>
> 对照判据：$x_0 \ne 1$；$x_0, x_1, x_2$ 都不是 $-1$；$x_3$ 直接变成 $1$ 而不是 $-1$。**链上没出现 $-1$ ⇒ 561 是合数。**
>
> 顺手验证 3.2 节的"捞因子"：$67^2 \equiv 1 \pmod{561}$ 而 $67 \not\equiv \pm 1 \pmod{561}$，于是
>
> ```
> gcd(67 - 1, 561) = gcd(66, 561) = 33        561 = 33 × 17
> ```
>
> 同一个 561，费马测试看到 $2^{560} \equiv 1 \pmod{561}$ 就放行；Miller-Rabin 检查的是**链上的中间项**，伪装在 $x_3 = 1$ 之前那一步就破了。
>
> 合法的链只有三种形态（以 $s = 5$ 为例）：
>
> ```
> x_0 = 1                                         → 通过
> x_0 = -1                                        → 通过
> x_0, x_1 ≠ ±1,  x_2 = -1,  x_3 = 1,  x_4 = 1     → 通过（-1 之后必然全是 1）
> ```

using u64 = std::uint64_t;
using u128 = __uint128_t;   // GCC / Clang 的 128 位整数

// ---------- 模乘 (a * b) % m ----------
// a、b 都 < m，直接乘会溢出 64 位，用 128 位承接中间结果
u64 mul_mod(u64 a, u64 b, u64 m) {
    return (u64)((u128)a * b % m);
}

// ---------- 快速幂 base^exp % m ----------
u64 pow_mod(u64 base, u64 exp, u64 m) {//底数、指数、模数
    u64 ans = 1 % m;
    base %= m;
    while (exp) {
        if (exp & 1ULL) ans = mul_mod(result, base, m);
        base = mul_mod(base, base, m);
        exp >>= 1;
    }
    return ans;

// ---------- Miller-Rabin ----------
// 这 7 个底数对 n < 2^64 是确定性的（结果不是概率性的）
const u64 WITNESSES[7] = {2, 325, 9375, 28178, 450775, 9780504, 1795265022};

bool miller_rabin(u64 n) {
    if (n < 2) return false;                    // 0、1 不是素数
    if (n == 2 || n == 3) return true;          // 小素数特判
    if (n % 2 == 0) return false;               // 大于 2 的偶数必为合数

    // 把 n-1 写成 2^s * d	(d 为奇数)
    u64 d = n - 1;
    int s = 0;
    while ((d & 1ULL) == 0) { //不断提出2，直到剩余的d为质数
        d >>= 1; 
        ++s; 
    }
    
    for (u64 a : WITNESSES) {
        u64 x = a % n;
        if (x == 0) continue;                   // a 是 n 的倍数：这一轮无意义，跳过
    
        u64 y = pow_mod(x, d, n);// y = x_0 = a^d mod n
        if (y == 1 || y == n - 1) continue;     // x_0 = ±1，这一轮通过
    
        bool passed = false;
        for (int i = 1; i < s; ++i) {           // 平方 s-1 次：x_1 ... x_{s-1}
            y = mul_mod(y, y, n);//y1=x_1=x_0^2%n
            if (y == n - 1) { //x_i同余1(mod n) 得出x_i值为-1
                passed = true; //直接判为通过
                break; 
            }
        }
        if (!passed) return false;              // 链上没出现 -1 ⇒ n 是合数
    }
    return true;

}
