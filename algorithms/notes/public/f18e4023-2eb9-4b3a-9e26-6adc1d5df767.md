# 贪心学习导航

**阅读顺序：贪心入门 → 贪心分类第 1、2 章 → 开始做题；第 3～8 章与贪心注意事项按需查阅。**

## 三篇文章

### 第一篇：贪心入门

[阅读《贪心入门》](<贪心入门.md>)

对应原第 0 章，保留 0.1～0.5 编号：先用买商品、递增数组理解两种基本选择，再用找零反例理解局部最优与全局最优。

### 第二篇：贪心分类

[阅读《贪心分类》](<贪心分类.md>)

对应原第 1～8 章，保留题单分类与 §1.1、§2.1 等小节编号：

- **先掌握第 1、2 章**：基本贪心策略、区间贪心。先学常见模型，再通过题目训练证明。
- **随后开始做题**：从每节推荐题目入手，不必等所有分类学完。
- **第 3～8 章按需扩展**：字符串、数学、思维、构造、交互与关联模型。

### 第三篇：贪心注意事项

[阅读《贪心注意事项》](<贪心注意事项.md>)

由原第 9～12 章合并并重新编号：

1. 怎样把直觉写成证明。
2. 贪心与动态规划。
3. 实现与验证。
4. 练习路线。

这是做题过程中的参考篇，无须全部读完再开始练习。

## 什么程度可以开始做题？

能对一道基础题说明下面三点，就可以开始对应练习：

1. **怎么选**：处理顺序与每一步的选择是什么？
2. **为什么对**：这个选择为什么不会失去最优解？
3. **什么时候失效**：哪些题目条件是证明不可缺少的？

开始做题不等于已经掌握所有贪心。后续通过新题补充模型，并逐步提高证明的严谨程度。
