> ### P3629 [APIO2010] 巡逻
>

## 1.思路：

本题原图一共 n 个节点，n-1 条边，可知为一棵有根树，

从根节点 1  开始遍历全部点一次并回到根节点，相当于对树进行一次DFS

可对样例手动计算，每条边向下到子节点时经过一次，回到根节点时再经过一次

总距离为 $2\times (n-1)$ 

## 2.k=1时建图

题目要求新增一条边，使经过这条边的遍历路径最小

应尽量优化更多的路线，所以想到寻找树的直径 d 并连接两端，此时减少的距离为: $d-1$

所以最优路线长度 $minLength=2\times(n-1)-(d-1)$ 

使用两次 dfs 求解直径，返回直径距离并计算最短距离，此时可以拿到 30 分

```cpp
const int MAXN=1e5+7;
const int MAXM=2e5+7;
struct edge{
    int to,nxt,val=1;
}edges[MAXM];
int n,k,head[MAXN],cnt=0;
void add(int u,int v){
    edges[cnt].to=v;
    edges[cnt].nxt=head[u];
    head[u]=cnt;
    cnt++;
}
//dfs求直径
int far=0,pot=0;	//直径大小、直径的一端编号
bool vis[MAXN];
void dfs(int x,int step){
    for(int i=head[x];~i;i=edges[i].nxt){
        int v=edges[i].to;
        if(!vis[v]){
            vis[v]=1;
            dfs(v,step+1);
        }
    }
    if(far<step){
        far=step;
        pot=x;
    }
}
```

## 3.k=2时

有 $70\%$ 的样例需要新建两条边，很容易想到再进行一次直径搜索

但是当两次的直径有重叠路径时，本来被省去的路径又被加入了遍历路线

所以将第一次的直径路径边权翻转，记为 -1，表示第二次遍历时选择这些边为直径不仅没有减少距离，反而增加了

由于要翻转直径的边权，所以第一次遍历求直径时记录父节点，之后按照父节点从直径一侧往回推导并将路径的边权取为 -1

注意：取反边权时一定要将两个方向的边都取反(因为录入的是无向边) ，这里有一个小技巧：录入的无向边是相邻的，可以找到一个边后直接异或就可以找到另一条

由于改边权后原图中出现了负边，所以不能再使用两次 dfs 求直径，而是使用树形DP递推直径：

> ### 树形DP原理：
>
> 记 $f[i]=max_{1\le j\le k} f[j]+w(i,j)$ 即 $f[i]$ 为 $i$ 的最大子树
>
> 可知以 $i$ 为根的最大直径为 $maxLength_i=max(f[j]+w(i,j)+f[k]+w(i,k))$ , 其中 $j,k$ 均为 $i$ 的子节点且 $j\neq k$ 
>
> 实际求解时没有必要维护次大值，而是直接使用 $f[i]$ 装载已遍历子树的最大值，在剩下的遍历中每次使用当前子树大小+ $f[i]$ 刷新 $maxLength$ 

同样求出直径的距离，最小总路径：$minLength'=minLength+w'-1$

## 完整代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
const int MAXN=1e5+7;
const int MAXM=2e5+7;
//链式前向星存边，fa额外记录父节点
struct edge{
    int to,nxt,val=1;
}edges[MAXM];
int n,k,head[MAXN],cnt=0,fa[MAXN];
void add(int u,int v){
    edges[cnt].to=v;
    edges[cnt].nxt=head[u];
    head[u]=cnt;
    cnt++;
}
//dfs求直径+端点
int far=0,pot=0;
bool vis[MAXN];
void dfs(int x,int step){
    for(int i=head[x];~i;i=edges[i].nxt){
        int v=edges[i].to;
        if(!vis[v]){
            vis[v]=1;
            fa[v]=x;
            dfs(v,step+1);
        }
    }
    if(far<step){
        far=step;
        pot=x;
    }
}
//改变第一次求得直径的路径上边权
void change(int x){
    for(int i=head[x];~i;i=edges[i].nxt){
        int v=edges[i].to;
        if(v==fa[x]){
            edges[i].val=-1;
            edges[i^1].val=-1;  //更改无向图的另一条边，因为录入时两条边相邻，故可以使用异或直接找到另一条边
            change(v);
        }
    }
}
//树形DP求解第二次直径
int f[MAXN],mlen=0;
void treedp(int x){
    for(int i=head[x];~i;i=edges[i].nxt){
        int v=edges[i].to,w=edges[i].val;
        if(!vis[v]){
            vis[v]=1;
            treedp(v);
            mlen=max(mlen,f[x]+f[v]+w);
            f[x]=max(f[x],f[v]+w);
        }
    }
}
//输入+初始化+计算汇总
void solve(){
    cin>>n>>k;
    memset(head,-1,sizeof(int)*(n+1));
    for(int i=1;i<=n-1;i++){
        int u,v;
        cin>>u>>v;
        add(u,v);
        add(v,u);
    }
    memset(fa,0,sizeof(int)*(n+1));
    memset(vis,false,sizeof(bool)*(n+1));
    vis[1]=1;
    dfs(1,0);
    memset(fa,0,sizeof(int)*(n+1));
    memset(vis,false,sizeof(bool)*(n+1));
    far=0;
    vis[pot]=1;
    dfs(pot,0);
    int ans=2*(n-1)-far+1;
    if(k==1){
        cout<<ans<<'\n';
        return;
    }
    change(pot);
    mlen=0;
    memset(f,0,sizeof(int)*(n+1));
    memset(vis,false,sizeof(bool)*(n+1));
    vis[1]=1;
    treedp(1);
    cout<<ans-mlen+1<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    //cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
