> ### 题目：
>
> ### CF2273A Lavencia Oranges
>
> ## 题目描述
>
> René 在经历两年寒冷的 Lavencia 生活后，即将离开，手头有 $n$ 个 Lavencia 橙子和 $n$ 个空袋子（编号从 $1$ 到 $n$），每个橙子和袋子也都编号 $1$ 到 $n$。René 按照数组 $a$ 装橙子：第 $i$ 个橙子放入编号为 $a_i$ 的袋子。
>
> Lavencia 对出口有严格的检验流程，由 Jacqueline 执行：她选择一个整数 $s$，并没收所有恰好装有 $s$ 个橙子的袋子，取使 René 被没收橙子数最多的 $s$。数组 $a$ 的代价定义为 Jacqueline 可以没收的最大橙子数。
>
> 更正式地，给定数组 $a$，令 $c_i$ 表示在 $a$ 中恰好出现 $i$ 次的元素个数。则 $a$ 的代价为：
> $$
>  \max_{0 \le i \le n} i \cdot c_i 
> $$
>
> 给定 $n$，请构造一个数组 $a$，使得代价最小。
>
> ## 输入格式
>
> 每个测试点包含若干测试用例。第一行包含测试用例个数 $t$（$1 \le t \le 10^4$）。接下来 $t$ 行每行包含一个整数 $n$（$1 \le n \le 2 \cdot 10^5$）。
>
> 保证所有测试用例的 $n$ 之和不超过 $2 \cdot 10^5$。
>
> ## 输出格式
>
> 对每个测试用例输出两行。
>
> 第一行输出一个整数——最小可能代价。
>
> 第二行输出 $n$ 个整数 $a_1,a_2,\ldots,a_n$（$1 \le a_i \le n$）——任意一个能实现最小代价的方案。
>
> ## 输入输出样例 #1
>
> ### 输入 #1
>
> ```
> 3
> 4
> 5
> 8
> ```
>
> ### 输出 #1
>
> ```
> 2
> 1 2 3 3
> 3
> 1 1 2 2 2
> 3
> 4 2 1 5 1 3 1 3
> ```
>
> ## 说明/提示
>
> 在第一个测试用例中，René 分别向四个袋子中放了 $1$、$1$、$2$、$0$ 个橙子。当 Jacqueline 选择 $1$ 时，她没收了袋子 $1$ 和 $2$，René 损失 $2$ 个橙子。选择 $2$ 时，没收了袋子 $3$，也是 $2$ 个橙子。因此代价为 $2$。可以证明这是该情况下的最小代价。
>
> 在第二个测试用例中，袋子 $1$ 中有 $2$ 个橙子、袋子 $2$ 有 $3$ 个、其它袋子为空。选择 $2$ 时，René 损失 $2$ 个橙子，选择 $3$ 时损失 $3$ 个橙子，因此代价为 $3$。也可以证明在这个情况下 $3$ 是最小代价。

## 思路：

先通过给出的样例寻找规律：

$4\rightarrow 1+1+2$

$5\rightarrow 3+2$

$8\rightarrow 1+1+1+2+3$

可以归纳出要使损失 $k$ 尽可能小，原式的形式必定是 $k+a_1*(k-1)+a_2*(k-2)\dots a_{k-1}*1$

(这里的 $a_i$ 代表装有 $i$ 个橙子的袋子个数)，即其他数量小于 $k$ 的袋子总贡献不能大于 $k$

易发现符合要求的总可装橘子数量会随 $k$ 增大而增大，单调所以考虑二分 $k$ 的大小

判断一个 $k$ 是否成立，可以以“每种袋子贡献不超过 $k$ 的构造中，橙子装载量是否小于 $n$ ”判定

最终输出最小的合法 $k$ 时的构造即可

## 代码:

 ```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
int n,l=1,r;
vector<int> ans;    //每种数量
//check 函数判定当前 k 是否有合法装载方案
bool check(int mid){
    vector<int> v(mid+1,0);
    v[mid]=1;
    int les=n-mid;
    for(int i=mid-1;i>1;i--){
        int mn=min(les/i,mid/i);	//贪心：每袋尽量装更多，同时要保证总数量不超过 n
        v[i]=mn;
        les-=i*mn;
        if(les<0) break;
    }
    if(les>=0&&les<=mid){	//剩余量在 0~mid之间，可以直接每袋一个处理掉
        v[1]=les;
        ans=move(v);
        return true;
    }else{	//无法凑出合法方案
        return false;
    }
}
void solve(){
    cin>>n;
    if(n==1){	//特判1
        cout<<1<<'\n';
        cout<<1<<'\n';
        return;
    }
    if(n==2){//特判2
        cout<<2<<'\n';
        cout<<1<<' '<<1<<'\n';
        return;
    }
    ans.clear();	//每个Test重置变量
    l=1,r=n;
    while(r-l>1){	//二分答案找 k
        int mid=(r+l)>>1;
        if(check(mid)){
            r=mid;
        }else{
            l=mid;
        }
    }
    cout<<r<<'\n';
    int bucket=1;	//输出，单独记录袋子的编号
    for(int i=1;i<=r;i++){
        for(int j=0;j<ans[i];j++){
            for(int k=1;k<=i;k++){
                cout<<bucket<<' ';
            }
            bucket++;
        }
    }
    cout<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
 ```

注意点：

1. $n=1/n=2$ 时不会进循环，所以要特判返回处理好的答案/先初始化ans，保证最后输出不为空值

2. 每轮测试一定要重置 $l$ 和 $ans$ ,防止下一轮读到上一轮的报错
3. check 中一定要判断当前剩余量是否够 i 减去，另外 check 内还可以再开一轮二分寻找每种的最大可取值
