# [[题解]P1031 [NOIP 2002 提高组] 均分纸牌](https://www.luogu.com.cn/problem/P1031)

> ### 题目：
>
> #### 题目描述
>
> 有 $N$ 堆纸牌，编号分别为 $1,2,\ldots,N$。每堆上有若干张，但纸牌总数必为 $N$ 的倍数。可以在任一堆上取若干张纸牌，然后移动。
>
> 移牌规则为：在编号为 $1$ 堆上取的纸牌，只能移到编号为 $2$ 的堆上；在编号为 $N$ 的堆上取的纸牌，只能移到编号为 $N-1$ 的堆上；其他堆上取的纸牌，可以移到相邻左边或右边的堆上。
>
> 现在要求找出一种移动方法，用最少的移动次数使每堆上纸牌数都一样多。
>
> 例如 $N=4$ 时，$4$ 堆纸牌数分别为 $9,8,17,6$。
>
> 移动 $3$ 次可达到目的：
>
> - 从第三堆取 $4$ 张牌放到第四堆，此时每堆纸牌数分别为 $9,8,13,10$。
> - 从第三堆取 $3$ 张牌放到第二堆，此时每堆纸牌数分别为 $9,11,10,10$。
> - 从第二堆取 $1$ 张牌放到第一堆，此时每堆纸牌数分别为  $10,10,10,10$。
>
> #### 输入格式
>
> 第一行共一个整数 $N$，表示纸牌堆数。  
> 第二行共 $N$ 个整数 $A_1,A_2,\ldots,A_N$，表示每堆纸牌初始时的纸牌数。
>
> #### 输出格式
>
> 共一行，即所有堆均达到相等时的最少移动次数。
>
> #### 输入输出样例 #1
>
> ##### 输入 #1
>
> ```
> 4
> 9 8 17 6
> 
> ```
>
> ##### 输出 #1
>
> ```
> 3
> 
> ```
>
> #### 说明/提示
>
> 对于 $100\%$ 的数据，$1  \le  N  \le  100$，$1 \le  A_i  \le 10000$。
>
> **【题目来源】**
>
> NOIP 2002 提高组第一题

## 思路：

首先，"最小操作次数"很容易想到和DP/贪心沾边

对样例进行模拟：

- 计算每个牌堆相比平均值多/差多少牌： $-1,-2,7,-4$
- 从多出的牌堆中抽出 3 张，移至左侧： $-1,1,4,-4$
- 再次移动一张: $0,0,4,-4$
- 最后抽出 4 张移至右侧

通过整个样例模拟，可以发现每次抽出刚好使更小堆达到平均值的牌数最优，所以直接考虑贪心

反向看整个给牌操作，其本质是小于平均值的牌堆向右拿取足量的牌，大于平均值的牌堆向右给予多余的牌

所以直接从左向右贪心，每次拿牌/给牌都记一次操作，最终统计并输出：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

void solve(){
    int n;
    cin>>n;
    ll sum=0,div=0,ans=0;
    vector<int> v(n);
    for(auto& a:v) {
        cin>>a;
        sum+=a;
    }
    div=sum/n;
    for(int i=0;i<n;i++){
        if(v[i]<div){	//牌堆少牌
            v[i+1]-=(div-v[i]);	//向右拿牌
            ans++;
        }
        if(v[i]>div){	//牌堆多牌
            v[i+1]+=(v[i]-div);	//向右给牌
            ans++;
        }
        //刚好等于平均值就不操作
    }
    cout<<ans<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    //cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
