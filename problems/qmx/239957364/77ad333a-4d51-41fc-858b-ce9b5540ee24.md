> ## 题目：
>
> ### CF2285C Max Substitution
>
> #### 题目描述
>
> 给定一个长度为 $n$ 的数组 $a$。在一次操作中，你可以将 $a$ 中唯一的最大元素替换为任意严格小于它的正整数（即满足 $1 \le x < \max(a)$ 的任意整数 $x$）。仅当 $a$ 中存在唯一的最大元素时，你才能执行此操作。
>
> 请计算通过执行任意次（可以为零次）操作能够得到的不同数组的数量。由于答案可能很大，请将结果对 $10^9+7$ 取模后输出。
>
> 注：如果两个数组 $a$ 和 $b$ 至少在一个位置上不同（即存在下标 $i$ 使得 $a_i \ne b_i$），则认为它们是不同的。
>
> #### 输入格式
>
> **本题有多组测试数据**。第一行包含一个整数 $t$（$1 \le t \le 1000$），表示测试数据的组数。
>
> 对于每组测试数据：
>
> 第一行包含一个整数 $n$（$1 \le n \le 2 \cdot 10^5$），表示数组的长度。
>
> 第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$（$1 \le a_i \le 10^9$），表示数组中的元素。
>
> 保证所有测试数据中 $n$ 的总和不超过 $2 \cdot 10^5$。
>
> #### 输出格式
>
> 对于每组测试数据，输出一行一个整数，表示通过执行任意次操作能得到的不同数组的数量，对 $10^9+7$ 取模。
>
> #### 输入输出样例 #1
>
> ##### 输入 #1
>
> ```
> 5
> 3
> 2 2 1
> 2
> 1000000000 1
> 4
> 6 7 2 2
> 3
> 3 4 2
> 1
> 1
> ```
>
> ##### 输出 #1
>
> ```
> 1
> 1000000000
> 32
> 9
> 1
> ```
>
> #### 说明/提示
>
> 在第一组测试数据中，由于最大元素 $2$ 不唯一，唯一能得到的数组只有初始数组 $[2,2,1]$。
>
> 在第二组测试数据中，最大元素为 $10^9$。可以证明，经过任意次操作后，可能得到的数组为 $[1,1], [2,1], [3,1], \ldots, [10^9,1]$。因此答案为 $10^9$。
>

## 思路：

这道题求替换任意次最大值后的所有组合数

本题所求与数组元素顺序无关，所以直接降序排序

若原数组中最大值数量 $\ge2$ ,则不可替换，直接输出 1 

最大值仅有一个，考虑其可变成的数值：

令最大值为 $v_1$ , 由题可知 $v_1$ 可以替换的值一共 $v_1-1$ 种

下一个值 $v_2$ 要成为新的最大值变换自身，需要 $v_1$ 变为小于 $v_2$ 的值，而 $v_2$ 自己可变的种类为 $v_2-1$种

两种情况互相独立，组合后可构成的新数组种类为 $(v_2-1)^2$

再下一个值 $v_3$ 要成为新的最大值 ， 需要 $v_1$ 、$v_2$ 变换后的值均小于 $v_3$ 

$v_3$ 自己可以变成的值种类为 $v_3-1$

组合三者，可得新数组种类为 $(v_3-1)^3$ 

总结规律：对于每一个最大数 $v_i$ ,其可以构成的新数组种类为 $(v_i-1)^i$

边界：当原数组某个数出现次数超过 1 次时，其必定不可能改变为其他值，此时计数结束

公式：
$$
ans=1+\sum_{i=1}^{min(n,\text v_i出现超过两次时的i)} (v_i-1)^i
$$
记得取模

## 代码：

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
const int MAXN=2e5+7;
const int MOD=1e9+7;
int v[MAXN],n;
ll f_pow(ll a,ll b){
    a%=MOD;
    ll ans=1;
    while(b){
        if(b&1) ans=ans*a%MOD;
        a=a*a%MOD;
        b>>=1;
    }
    return ans;
}

void solve(){
    int n;
    cin>>n;
    for(int i=0;i<n;i++){
        cin>>v[i];
    }
    v[n]=0;
    if(n==1){
        cout<<v[0]<<'\n';
        return;
    }
    sort(v,v+n,greater());
    if(v[0]==v[1]){
        cout<<1<<'\n';
        return;
    }
    ll ans=1;
    for(int i=0;i<n;i++){
        if(i<n-1&&v[i]==v[i+1]){
            break;
        }
        ans=(ans+f_pow(v[i]-1,i+1))%MOD;
    }
    cout<<ans<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
