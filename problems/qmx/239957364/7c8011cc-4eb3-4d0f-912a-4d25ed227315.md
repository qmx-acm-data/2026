> 题目：
>
> Isaac 开始了他的训练。现有 n 条跑道，第 i 条跑道（1≤i≤n）由$ a_i $个长度相等的路段组成。
>
> 给定整数 u（$1≤u≤10^9$），每完成一个路段都会使 Isaac 的能力值提升一个特定数值，具体如下：
>
> - 完成第 1 个路段会使 Isaac 的能力值提升 u。
> - 完成第 2 个路段会使 Isaac 的能力值提升 u−1。
> - 完成第 3 个路段会使 Isaac 的能力值提升 u−2。
> - …
> - 完成第 k 个路段（k≥1）会使 Isaac 的能力值提升 u+1−k。（u+1−k 的值可能为负数，这意味着多完成一个路段会使 Isaac 的能力值降低。）
>
> 另外给定一个整数 l。你必须选择一个整数 r，满足$ l≤r≤n$，并且 Isaac 将完成跑道 $l,l+1,…,r $中**每条**跑道的**每个**路段（即总共完成$ ∑^r_{i=l}a_i=a_l+a_{l+1}+…+a_r$ 个路段）。
>
> 请回答以下问题：应选择哪个最优的 r，才能使 Isaac 的能力值提升尽可能大？
>
> 如果存在多个使 Isaac 的能力值提升最大的 r，输出其中**最小**的 r。
>
> 为了增加难度，对于 q 组不同的 l 和 u，你都需要回答该问题。
>
> **输入**
>
> 输入的第一行包含一个整数 $t$（$1 \le t \le 10^4$）——测试用例的数量。
>
> 接下来是各测试用例的描述。
>
> 对于每个测试用例，第一行包含一个整数 $n$（$1 \le n \le 10^5$）。
>
> 第二行包含 $n$ 个整数 $a _ 1, a _ 2, \ldots, a _ n$（$1 \le a _ i \le 10^4$）。
>
> 第三行包含一个整数 $q$（$1 \le q \le 10^5$）。
>
> 接下来的 $q$ 行每行包含两个整数 $l$ 和 $u$（$1 \le l \le n, 1 \le u \le 10^9$）——每个查询的描述。
>
> 所有测试用例中 $n$ 的总和不超过 $2 \cdot 10^5$。所有测试用例中 $q$ 的总和不超过 $2 \cdot 10^5$。

## 1. 从过程到数学模型

所有跑道总共完成 k 个路段时，收益只取决于 k，与这些路段来自哪条跑道无关。

例如 u=3，逐段收益为 3,2,1,0,-1,-2；总收益依次是 3,5,6,6,5,3。

等差数列求和：

$F(k)=u+(u-1)+...+(u+1-k)=k*u-k*(k-1)/2$。

这里 k 是**本次查询从 L 开始完成的段数**，不是全局前缀和。

设 s[0]=0，$s[i]=a[1]+...+a[i]$，则选择 r 对应$k(r)=s[r]-s[l-1]$，且必须 $l<=r<=n$。

暴力枚举所有 r，每次 O(1) 计算 F，总计每次查询 O(n)、整体 O(nq)，最坏约 $10^{10}$ 量级，不能接受。

## 2. 从差分找峰值

$F(k+1)-F(k)=u-k。$

- $k<u$：再做一段收益为正，总收益增加。
- $k=u$：再做一段收益为零，$F(u)=F(u+1)$。
- $k>u$：再做一段收益为负，总收益减少。

所以整数峰顶是$ u $和 $u+1$，而非仅 u。

注意：这描述的是“每增加一个路段”，不是“每增加一条跑道”。一条跑道可能跨过峰值，所以不能只看是否超过 u，也不能简单选择不超过 u 的最大前缀。

例如 $a=[1,2],l=1,u=2$：可行段数只有 1 和 3，收益分别 2 和 3，正确终点是 2，必须允许超过 u。

## 3. 为什么只比较两个终点

设 p 为第一个满足 $k(p)>=u$ 的合法终点，即

$s[p]>=s[l-1]+u$。

因此可以在$ s[l..n]$ 中 $lower\_ bound(s[l-1]+u)$。

正确性分三种情况：

1. p 不存在：所有可行 k<u，收益一直严格增加，最优 r=n。
2. p=l：最短合法段数已经 >=u。右侧收益不再增加，所以最优是 l，不能选择 l-1。
3. $l<p<=n$：
   - 所有 r<p 都满足 k(r)<u。越往右收益越大，左侧只需保留 p-1。
   - 所有 r>=p 都满足 k(r)>=u。越往右收益不增加，右侧最早的 p 不劣于后续任何终点。
   - 因此全局最优必在 {p-1,p} 中。比较真实收益，相等时选 p-1。

## 4.源代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

void solve(){
    int n;
    cin>>n;
    vector<ll> pre(n+1,0);
    for(int i=1;i<=n;i++){
        cin>>pre[i];
        pre[i]=pre[i-1]+pre[i];//前缀和
    }
    int q;
    cin>>q;
    for(int i=0;i<q;i++){
        int l,u;
        cin>>l>>u;
        if(n==1){
            cout<<1<<' ';
            continue;
        }
        auto pos=lower_bound(pre.begin()+l,pre.end(),u+pre[l-1]);//二分寻找最优点
        if(pos==pre.end()) {//全选也达不到段数u
            cout<<n<<' ';
        }else{
            ll p=pos-pre.begin(),t1=pre[p]-pre[l-1],t2=pre[p-1]-pre[l-1];//左侧最优/右侧最优点
            cout<<(p==l||(t1*u-t1*(t1-1)/2)>(t2*u-t2*(t2-1)/2)? p:p-1)<<' ';
        }
    }
    cout<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```



## 错因分析
vp时选择求两侧至峰顶点的距离(损失量），而右侧的第一个点的收益量为0，不能简单套用公式n(n+1)/2

## Trick
对于单峰函数，二分前缀和/离散化可以直接求最优值，同时条件允许使用公式比优化trick更加稳定
