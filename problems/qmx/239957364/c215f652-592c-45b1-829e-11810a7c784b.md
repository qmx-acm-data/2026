***题目：***

> #### P17731 [ICPC 2019 Xuzhou R] Cat
>
> ##### 题目描述 
>
> Yen-Jen 非常喜欢猫。
>
> 现在，有 $10^{18}$ 只猫排成一行，其中第 $i$ 只猫的代价 $c_i$ 等于 $i$，第 $i$ 只猫的编号也等于 $i$。
>
> 现在，Yen-Jen 想要购买编号连续的一些猫，但他只有 $S$ 元钱。为了购买编号为 $x, x+1, \cdots, y-1, y$ 的猫，他需要花费 $x \oplus (x+1) \oplus \cdots \oplus (y-1) \oplus y$ 元钱，其中 $\oplus$ 表示按位异或运算符。
>
> 现在，他想向你提出 $T$ 个询问。在每个询问中，他拥有 $S$ 元钱，并且希望所买猫的编号落在区间 $[L, R]$ 内。Yen-Jen 最多能买多少只猫？如果他一只猫也买不了，请输出 `-1`。
>
> ##### 输入格式
>
> 第一行包含一个整数 $T$，表示 Yen-Jen 想要向你发起的询问个数。
>
> 接下来 $T$ 行，每行描述一个询问。每行包含三个整数 $L, R, S$，表示 Yen-Jen 拥有 $S$ 元钱，并且希望购买编号在 $[L, R]$ 范围内的猫。
>
> - $1 \le T \le 5 \times 10^5$
> - $1 \le L \le R \le 10^{18}$
> - $0 \le S \le 2 \times 10^{18}$
>
> ##### 输出格式
>
> 对于每个询问，输出 Yen-Jen 能够购买的最大猫的数量。如果 Yen-Jen 一只猫也买不了，则输出 `-1`。
>
> ##### 输入输出样例 #1
>
> ###### 输入 #1
>
> ```
> 2
> 1 1 0
> 2 2 2
> ```
>
> ###### 输出 #1
>
> ```
> -1
> 1
> ```

## 一、从题目约束出发，先判断方向

设：

$$
N=R-L+1.
$$

我们需要在 $[L,R]$ 中选一个非空子区间 $[x,y]$，满足：

$$
x\oplus(x+1)\oplus\cdots\oplus y\le S,
$$

最大化 $y-x+1$。

由于编号达到 $10^{18}$，不能逐只扫描；询问数达到 $5\times10^5$，也应优先寻找非常轻量的单次算法。

### 1. 为什么不能直接滑窗？

固定左端点 $1$，随着右端点增加：

$$
\begin{aligned}
1&=1,\\
1\oplus2&=3,\\
1\oplus2\oplus3&=0,\\
1\oplus2\oplus3\oplus4&=4.
\end{aligned}
$$

异或代价既会增加，也会减少。

例如 $S=0$：

- $[1,2]$ 不可行；
- 扩大成 $[1,3]$ 后反而可行。

所以，“超预算就移动左端点”的普通滑窗依据不存在。

### 2. 为什么不能直接二分长度？

对于：

$$
L=1,\quad R=3,\quad S=0,
$$

精确长度的可行性是：

| 长度 | 是否存在可行区间 |
| ---- | ---------------- |
| 1    | 否               |
| 2    | 否               |
| 3    | 是               |

它不是通常二分所需的“短的可行、长的不可行”。

注意：**“存在长度至少 $k$ 的可行区间”在逻辑上对 $k$ 单调，但如何高效判定仍是另一个问题。**不能把它与“检查精确长度 $k$”混为一谈。

## 二、第一步优化：区间异或 $O(1)$ 计算

定义：

$$
F(n)=0\oplus1\oplus2\oplus\cdots\oplus n.
$$

利用相同数出现两次会抵消：

$$
\boxed{\operatorname{xor}(x,y)=F(y)\oplus F(x-1)}.
$$

连续整数的前缀异或满足：

$$
F(n)=
\begin{cases}
n,&n\bmod4=0,\\
1,&n\bmod4=1,\\
n+1,&n\bmod4=2,\\
0,&n\bmod4=3.
\end{cases}
$$

### 公式从哪里来？

对于偶数 $a$，二进制最低位为 $0$，加一仅改变最低位，因此：

$$
a\oplus(a+1)=1.
$$

所以：

$$
(4k)\oplus(4k+1)\oplus(4k+2)\oplus(4k+3)=1\oplus1=0.
$$

把前面的完整四数块全部消掉，检查剩下的数，就能得到四类公式。

这里要区分：

> 是公式按 $n\bmod4$ 分类，不是 $F(n)$ 的数值每四项重复。

例如 $F(4)=4$，但 $F(8)=8$。

**做到这里，只解决了“检查一个区间很快”，还没有解决“应该检查哪些区间”。**

## 三、核心突破：为什么只需要考虑删掉至多 4 个数？

### 1. 先寻找“任何预算都允许”的代价

题目保证：

$$
S\ge0.
$$

所以：

> **只要构造出异或为 $0$ 的区间，它就一定可买。**

接下来不必首先研究一般的 $\operatorname{xor}\le S$，而是先研究一个更容易的目标：

**能不能找到一个很长的零异或区间？**

### 2. 零异或块的准确条件

对任意**偶数** $a$：

$$
\boxed{a\oplus(a+1)\oplus(a+2)\oplus(a+3)=0}.
$$

因为两对数的异或都是 $1$。

注意：

- 不要求 $a$ 是 $4$ 的倍数；
- 但不能省略“$a$ 为偶数”。

例如：

$$
2\oplus3\oplus4\oplus5=0,
$$

而：

$$
1\oplus2\oplus3\oplus4=4.
$$

因此：

> **从偶数开始，取长度为 $4$ 的倍数的区间，一定可以组成若干零异或块。**

### 3. 如何只删少量边界就满足这个条件？

假设 $N\ge5$。

1. #### 调整左端点

   - $L$ 为偶数：不删；
   - $L$ 为奇数：删去 $L$。

   于是左端点变为偶数，**最多删 $1$ 个数**。

2. #### 调整长度

从剩下的区间右端，删去若干个数，使长度成为 $4$ 的倍数。

任意整数除以 $4$ 的余数最多为 $3$，所以**最多再删 $3$ 个数**。

又因为原长度至少 $5$，左端调整后至少还剩 $4$ 个数，最终保留的区间非空。

因此：

$$
\boxed{\text{总删除量最多 }1+3=4}.
$$

我们构造出了一个：

- 非空；
- 异或为 $0$；
- 长度至少为 $N-4$

的可行区间。

### 4. 从“构造”到“限制最优解”

设最优答案为 $\mathrm{OPT}$。

既然已经找到一个长度至少 $N-4$ 的可行区间，就有：

$$
\mathrm{OPT}\ge N-4.
$$

从而：

$$
\boxed{N-\mathrm{OPT}\le4}.
$$

这意味着：

> **最优解从整个 $[L,R]$ 的两端，总共删掉的数不会超过 $4$ 个。**

这一步才是将巨大搜索空间压成常数规模的关键。

### 5. 长度不足 5 怎么办？

若 $N\le4$，任何非空子区间的总删除量都至多：

$$
N-1\le3.
$$

所以枚举删除量 $0\sim4$，同样覆盖全部可能答案。

大小区间的证明至此闭合。

## 四、枚举候选——为什么是 15 个候选？

设：

- 左边删掉 $a$ 个；
- 右边删掉 $b$ 个；
- 总删除量 $d=a+b$。

对应区间为：

$$
[L+a,\ R-b]=[L+a,\ R-(d-a)].
$$

我们枚举：

$$
d=0,1,2,3,4,
$$

每个 $d$ 中再枚举：

$$
a=0,1,\ldots,d.
$$

总候选数最多：

$$
1+2+3+4+5=\boxed{15}.
$$

并且同一层候选长度都为：

$$
N-d.
$$

因此按 $d$ 从小到大枚举，**第一个可行候选就是最长答案**。

- ### 伪代码


```text
for 总删除量 d = 0..min(4, N-1):
    for 左删除量 a = 0..d:
        x = L+a
        y = R-(d-a)
        如果区间异或 <= S:
            返回 N-d

返回 -1
```

正确性的核心是：

1. 大区间已经证明最优删除量不超过 $4$；
2. 小区间所有非空候选也都被覆盖；
3. 对每个删除量，左右分配全部枚举；
4. 首次成功时，更长的候选已经全部被排除。

## 五、C++17 实现

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

ll pre_xor(ll n){	//连续整数异或和查值表
    switch (n%4){
    case 0:
        return n;
        break;
    case 1:
        return 1;
        break;
    case 2:
        return n+1;
        break;
    case 3:
        return 0;
        break;
    }
} 

void solve(){
    ll l,r,s;
    cin>>l>>r>>s;
    for(int d=0;d<min(5ll,r-l+1);d++){	//枚举总删除数d
        for(int a=0;a<=d;a++){//枚举左删除数a
            if((pre_xor(r-(d-a))^pre_xor(l+a-1))<=s){//从大到小枚举，符合要求的直接为答案
                cout<<( r-l+1-d)<<'\n';
                return;
            }
        }
    }
    cout<<-1<<'\n';//没有符合要求的方案 返回-1
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```

**复杂度：**

- 单次询问：最多 $15$ 次判定，最坏 $O(1)$；
- 全部询问：$O(T)$；
- 额外空间：$O(1)$，不需要预处理。

> ### 三个实现细节
>
> 1. **全部使用 `long long`**：包括编号、预算和答案。
> 2. **必须排除空区间**：否则可能把空区间异或 $0$ 当作答案，输出错误的 $0$。
> 3. **异或结果加括号再比较**：
>
> ```cpp
> (prefix_xor(y) ^ prefix_xor(x - 1)) <= S
> ```
>
> 不能省略括号；C++ 中比较运算的优先级高于按位异或。

- ## 这题应该提炼出什么解题方法？

1. #### 第一问：哪些维度太大，不能枚举？

   本题不能枚举编号、所有长度、所有端点组合。

2. #### 第二问：一个候选能否快速检查？

   利用前缀异或，把区间判定压到 $O(1)$。

3. #### 第三问：能否先做出一个保证合法的解？

   因为 $S\ge0$，零异或区间一定合法。

4. #### 第四问：这个保证合法的解，距离理论上限有多远？

   距离全长至多 $4$。

5. #### 第五问：它能否限制最优解？

   能。最优解不会比已经构造出来的可行解更差，因此只需要检查总损失不超过 $4$ 的情况。

可以抽象成一般方法：

> 若最大化保留长度的问题中，能保证构造出长度至少 $N-K$ 的可行解，那么只需枚举总删除量不超过 $K$ 的候选。

左右端删除量组合共有：

$$
\frac{(K+1)(K+2)}2
$$

种。**但 $K$ 必须来自证明，不能来自经验猜测。**
