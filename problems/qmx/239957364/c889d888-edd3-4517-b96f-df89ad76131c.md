> ### 题目：
>
> ### CF1900D Small GCD
>
> ### 题目描述
>
> $ a, b, c $ 为整数，定义 $ f(a, b, c) $ 如下:
>
> 将三个数排序，使得 $ a \le b \le c $。则函数返回 $ \gcd(a, b) $ , 这里 $ \gcd(a, b) $ 表示 [最大公约数 (GCD)](https://en.wikipedia.org/wiki/Greatest_common_divisor) 。简而言之，函数返回较小的两个数的最大公约数。
>
> 你会得到数组 $ a $，包含 $ n $ 个元素。求 $ f(a_i, a_j, a_k) $ 之和，其中 $ 1 \le i< j < k \le n $。
>
> 形式化的讲，求 $ \sum_{i = 1}^n \sum_{j = i+1}^n \sum_{k =j +1}^n f(a_i, a_j, a_k)$。
>
> ### 输入格式
>
> 第一行一个整数 $ t \ ( 1 \le t \le 10 )$ 为数据组数。
>
> 每组数据第一行为 $ n \ (3 \le n \le 8 \cdot 10^4) $，第二行为 $ a_1, a_2, \ldots, a_n $ ( $ 1 \le a_i \le 10^5 $ )  。
>
> 所有数据中 $ n $ 的和不超过 $ 8 \cdot 10^4 $。
>
> ### 输出格式
>
> 对每组数据，输出题中要求计算的求和。
>
> ### 输入输出样例 #1
>
> ### 输入 #1
>
> ```
> 2
> 5
> 2 3 6 12 17
> 8
> 6 12 8 10 15 12 18 16
> ```
>
> ### 输出 #1
>
> ```
> 24
> 203
> ```

## 思路：利用容斥原理去重并求解前缀gcd值

题目求 $\sum^n_{i=1} \sum^n_{j=i+1} \sum^n_{k=j+1}gcd(a[i],a[j],a[k])(1<=i<j<k<=n)$

暴力枚举总复杂度为 $O(n^3logn)$

先结合题意优化枚举：

对于 $gcd(a[i],a[j],a[k])$ ,最终解仅与 $a[i]、a[j]$ 相关

故可以枚举 $k$ 位置，每个 $k$ 与所有可能 $i , j$ 构成贡献 ，复杂度降为$O(n^2log)$

可以发现朴素枚举 $i,j$ 并求解 gcd 过于缓慢，且对于从左至右枚举的 k ，其前缀中有大量重复计算的数对

从左向右枚举天然包含了所有 k 的可能，所以不再枚举 k 而是枚举 j ，逐轮计算 j 可以与前缀构成的所有 gcd

依据性质：
$$
gcd(a,b)=d \ =>\ a|d,b|d
$$
可反向思考：既然遍历枚举 i 在总元素 n 极大时非常费时，而 gcd 的值只包含于两数的因子，在本题限制下不超过 128

那就不再枚举$a[i]$并在线计算，而是枚举 $a[i]$ 与当前 $a[j]$ 可能的gcd值，

很容易想到通过 $i ,j$ 相同因子确定 gcd ，但对于 $i|j$ 而言 ，这种计数方法会重复计算可能 gcd

如 $a[i]=4 , a[j]=8$ ,两者重复的因子有 $1,2,4$ 三种，所以统计时 $1,2,4$ 都会被计入

所以逐步枚举并排除"含有这个因子但最终 gcd 不等于该值的数"

> 注：这一步可以通过容斥定律解释：求解全集时先将多个重叠的集合累加， 再逐步减去重复计数的部分

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;
const int MAXN=8e4+7,MAXA=1e5+7;
int v[MAXN],mul[MAXA],gnums[MAXA];      //v：原数据，mul[i]:前缀中i的倍数的个数，gnums[i]：对于每个右基准数 a[r],与前缀 gcd值刚好为 i的数

void solve(){
    memset(mul,0,sizeof(mul));
    memset(gnums,0,sizeof(gnums));
    int n;
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>v[i];
    }
    sort(v+1,v+1+n);
    vector factors(MAXA,vector<int>());
    for(int i=1;i<MAXA;i++){
        for(int j=i;j<MAXA;j+=i){
            factors[j].push_back(i);
        }
    }
    for(int i=1;i<MAXA;i++) reverse(factors[i].begin(),factors[i].end());
    ll ans=0,tmp=0;
    for(int i=1;i<=n;i++){//通过容斥原理寻找最大gcd，原理见下
        ans+=tmp;
        for(auto& a:factors[v[i]]){//gcd可能值
            gnums[a]=mul[a];
            for(auto& b:factors[v[i]/a]){   //容斥减去不相等gcd值
                if(b!=1) gnums[a]-=gnums[b*a];
            }
            tmp+=1ll*a*gnums[a];
        }
        for(auto& a:factors[v[i]]) mul[a]++;
    }
    cout<<ans<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```

> $mul[i]$ :可被 i 整除的前缀数据数量，如$i、2i、3i\dots$ (换种说法就是 i 和 i 的倍数的数量)
>
> $gnums[i]$ :与当前处理值的 gcd 等于 i 的前缀数据数量：
>
> 枚举当前处理值 `v[i]` 的因子 a ：
>
> ```cpp
> for(auto& a:factors[v[i]]){//gcd可能值
> ```
>
> 初始化`gnums[a]=mul[a]`：假设所有的可被整除前缀值与待处理数 gcd 都为 i
>
> ```cpp
> gnums[a]=mul[a];
> ```
>
> 最重要的一步：排除重复值
>
> ```cpp
> for(auto& b:factors[v[i]/a]){   //容斥减去不相等gcd值
>  if(b!=1) gnums[a]-=gnums[b*a];
> }
> tmp+=1ll*a*gnums[a];
> ```
>
> 枚举其他的因子反推元素：这一步组合出的数据除 b=1 外 gcd 均有更大值 ，此处将其排除避免重复计数
>
> > eg: $v[i]=12,v[j]=8$ ,相同因子有 $1,2,4$ 三个，但实际的 gcd 只有 4 一个
> >
> > 所以当 a=2 时，b=4 直接减去这份多余的贡献
> >
> > 同理可得为什么 b=1 时不消去：此时 a 为该值的最大因子,应该计算贡献
>
> 每一轮结尾统计当前数 $v[i]$ 的因子并计入 mul , 供下一轮复用
>
> ```cpp
> for(auto& a:factors[v[i]]) mul[a]++;
> ```

关于`reverse`:

设$v[i]=12$:

其因子为 1、2、3、4、6、12

现对于前缀序列2 3 4 6而言

$mul[2]=3  $(包含2,4,6)

可看作 $mul[2]=gnums[2]+gnums[4]+gnums[6]$

从小到大求解 $gnums[2]$ 时，$gnums[4]、gnums[6]$ 并未得出,答案出现偏差

所以从大到小遍历因子，保证遍历小因子时前置的大因子 gnums 已经被求出
