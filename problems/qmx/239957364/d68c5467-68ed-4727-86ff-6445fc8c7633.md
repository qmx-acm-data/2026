> 题目：
>
> ### 问题陈述
>
> 有 $N$ 个长度为 $M$、由小写英文字母组成的字符串。第 $i$ 个字符串 $(1\leq i\leq N)$ 为 $S _ i$。
>
> 求满足以下条件的整数对 $(i,j)$ $(1\leq i < j \leq N)$ 的数量。
>
> -   $S _ i$ 与 $S _ j$ 的汉明距离至多为 $2$。
>
> 什么是汉明距离？
>
> 长度均为 $k$ 的字符串 $A$ 和 $B$ 之间的汉明距离，是满足 $1\leq i\leq k$ 且 $A$ 的第 $i$ 个字符与 $B$ 的第 $i$ 个字符不同的整数 $i$ 的数量。例如，`abc` 与 `bac` 的汉明距离为 $2$，`atcoder` 与 `contest` 的汉明距离为 $7$。
>
> ### 限制条件
>
> -   $2 \leq N \leq 2\times 10^5$
> -   $2 \leq M \leq 6$
> -   $N$ 和 $M$ 是整数。
> -   $S _ i$ 是由小写英文字母组成的长度为 $M$ 的字符串。

## 1. 从朴素方法到可行方向

### 1.1 朴素枚举

对每个 `i<j`，扫描 `M` 个位置，若不同位置数不超过 2 就计数。复杂度 `O(N^2M)`。

### 1.2 枚举待匹配字符串的全部近邻

对当前字符串修改 0、1、2 个位置，再去哈希表查询。若字母表大小为 26，则一个字符串可能生成

`1 + 25M + 25^2 * C(M,2)`

个候选。即使通过去重和在线计数实现，`M=6` 时二次修改候选仍然很多；而且需要处理重复生成、计数方向和字符串构造，常数明显偏大。

### 1.3 反过来统计模式

距离不超过 2 的一对字符串必然在以下某种模式上相同：

- 距离 0：所有位置相同；
- 距离 1：删掉（通配掉）那个不同的位置后相同；
- 距离 2：通配掉两个不同的位置后相同。

因此可以先统计所有共享 0/1/2 通配模式的字符串对，再通过公式消除重复贡献。

## 2. 核心推导：三类模式计数

记：

- `x0`：汉明距离恰为 0 的对数；
- `x1`：汉明距离恰为 1 的对数；
- `x2`：汉明距离恰为 2 的对数。

对每种模式，用哈希表维护出现次数 `cnt[p]`。

已知所有字符串匹配共产生$n*m*(m-1)/2$

对于汉明距离为0的匹配串：

```cpp
A+=mat[str];    //记录完全匹配串并计数
mat[str]++;
```

每次取与str相等的子串数量，累加至计数器A中

对于汉明距离为1的匹配串：

```cpp
for(int i=0;i<m;i++){   //外循环 记录汉明距离为1的匹配串
    tmp[i]='/';
    B+=mat[tmp];
    mat[tmp]++;
    tmp[i]=str[i];
}
```

逐位替换处理子串为占位符`\`,表示除这位外其他位都对应匹配

对于汉明距离为2的匹配串：

```cpp
for(int i=0;i<m;i++){   //外循环 记录汉明距离为1的匹配串
    tmp[i]='/';
    for(int j=i+1;j<m;j++){     //内循环 记录汉明距离为2的匹配串
        tmp[j]='/';
        C+=mat[tmp];
        mat[tmp]++;
        tmp[j]=str[j];  //只把拆掉的字符拼回去
    }
    tmp[i]=str[i];
}
```

与上面相同，开双循环取匹配串并累加

## 3.去重并求解

####  3.1为什么 `x1 = A - M*x0`？

```cpp
const int x1 = B - 1LL * m * A;
```

先不要急着看公式，我们逐类观察：**一对字符串会在 `B `里被统计几次？**

### 情况一：距离为 0

例如：

```
abc
abc
```

两个字符串完全相同。无论把哪个位置变成 `?`，它们都会匹配：

| 通配位置 | 第一个字符串 | 第二个字符串 | 匹配？ |
| -------- | ------------ | ------------ | ------ |
| 第 1 位  | `?bc`        | `?bc`        | 是     |
| 第 2 位  | `a?c`        | `a?c`        | 是     |
| 第 3 位  | `ab?`        | `ab?`        | 是     |

因此，这**一对**字符串在 `B` 中被统计了 `m=3` 次。

推广到长度为 `m` 的字符串：

> 每一对距离为 0 的字符串，会对 `B` 贡献 `m` 次。

距离为 0 的对共有 `A` 对，所以它们总共贡献：

$m*A$

### 情况二：距离为 1

例如：

```
abc
acc
```

两者只有第 2 位不同：

```
abc
acc
 ↑
```

枚举单通配位置：

| 通配位置 | 第一个字符串 | 第二个字符串 | 匹配？ |
| -------- | ------------ | ------------ | ------ |
| 第 1 位  | `?bc`        | `?cc`        | 否     |
| 第 2 位  | `a?c`        | `a?c`        | 是     |
| 第 3 位  | `ab?`        | `ac?`        | 否     |

只有把**唯一不同的位置**通配掉，两者才能匹配。

因此：

> 每一对距离为 1 的字符串，对 `B` 恰好贡献 1 次。

共有 `b` 对，所以总共贡献 `b`。

### 情况三：距离至少为 2

例如：

```
abc
ade
```

第 2、3 位不同。只通配一个位置时，至少还会留下一个不同位置，因此不可能匹配。

所以距离至少为 2 的对，对 `B` 贡献 0。

### 合并起来

因此，`B` 的构成是：

B=距离 0 的贡献+距离 1 的贡献=$m*A+b$

我们想求的是 `b`，就把混在 `B` 里的距离 0 的贡献减掉：

$b=B-m*A$

也就是代码：

```cpp
const int b = B - 1LL * m * A;
```

## 3. 为什么 `x2` 要减去两项？

```cpp
const int c=C-a*(m*(m-1)/2)-(m-1)*b
```

现在 `C` 统计的是：**枚举所有两个通配位置后，匹配对出现的总次数。**

仍然逐类分析一对字符串的贡献。

### 情况一：距离为 0

例如：

```
abc
abc
```

它们原本完全相同，因此任选两个位置通配，结果都相同：

| 通配位置 | 第一个字符串 | 第二个字符串 | 匹配？ |
| -------- | ------------ | ------------ | ------ |
| 1、2     | `??c`        | `??c`        | 是     |
| 1、3     | `?b?`        | `?b?`        | 是     |
| 2、3     | `a??`        | `a??`        | 是     |

对长度 `m` 的字符串，任选两个位置有：
$$
\begin{pmatrix}
m \\
2
\end{pmatrix}
$$
种。

所以：

> 每一对距离为 0 的字符串，在 `C` 中贡献 `C(m,2)` 次。

共有 `a` 对，距离 0 的总贡献就是：

$a*C(m,2)$

------

### 情况二：距离为 1

例如：

```
abc
acc
```

它们只在第 2 位不同。

若通配两个位置，为了使两个字符串匹配，**必须通配第 2 位**。另一个位置可以从剩余的 `m-1` 个位置中任选。

当 `m=3` 时：

| 通配位置 | 第一个字符串 | 第二个字符串 | 匹配？ |
| -------- | ------------ | ------------ | ------ |
| 1、2     | `??c`        | `??c`        | 是     |
| 1、3     | `?b?`        | `?c?`        | 否     |
| 2、3     | `a??`        | `a??`        | 是     |

共匹配 `2=m-1` 次。

所以：

> 每一对距离为 1 的字符串，在 `C` 中贡献 `m-1` 次。

共有 `b` 对，距离 1 的总贡献就是：

$b*(m-1)$

------

### 情况三：距离为 2

例如：

```
abc
ade
```

第 2、3 位不同：

```
abc
ade
 ^^
```

通配两个位置后，两串要相同，就**必须恰好把这两个不同位置都通配掉**：

| 通配位置 | 第一个字符串 | 第二个字符串 | 匹配？ |
| -------- | ------------ | ------------ | ------ |
| 1、2     | `??c`        | `??e`        | 否     |
| 1、3     | `?b?`        | `?d?`        | 否     |
| 2、3     | `a??`        | `a??`        | 是     |

因此：

> 每一对距离为 2 的字符串，在 `C` 中恰好贡献 1 次。

共有 `c` 对，总贡献就是 `c`。

距离大于 2 的对无法只通过通配两个位置变得相同，贡献为 0。

合并起来:

$c=C-a*(m*(m-1)/2)-(m-1)*b$

## 源代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using ll=long long;

void solve(){
    int n,m;
    cin>>n>>m;
    vector<string> v(n);
    for(auto& a:v) cin>>a;
    unordered_map<string,int> mat;  //匹配串
    ll A=0,B=0,C=0;     //完全匹配/汉明距离1、2
    for(const string& str:v){
        A+=mat[str];    //记录完全匹配串并计数
        mat[str]++;
        string tmp=str;
        for(int i=0;i<m;i++){   //外循环 记录汉明距离为1的匹配串
            tmp[i]='/';
            for(int j=i+1;j<m;j++){     //内循环 记录汉明距离为2的匹配串
                tmp[j]='/';
                C+=mat[tmp];
                mat[tmp]++;
                tmp[j]=str[j];  //只把拆掉的字符拼回去
            }
            B+=mat[tmp];
            mat[tmp]++;
            tmp[i]=str[i];
        }
    }
    ll a=A,b=B-a*m,c=C-a*(m*(m-1)/2)-(m-1)*b;
    cout<<a+b+c<<'\n';
}
int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);
    cout.tie(0);
    int t=1;
    //cin>>t;
    while(t--){
        solve();
    }
    return 0;
}
```
