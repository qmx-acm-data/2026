## 题意

一个长度 $l$ 的字符串初始全是 `.`，之后反复把 `boy`、`girl` 贴上去，后贴的覆盖先贴的。每个单词最终至少有一个字符没被覆盖。给出最终串，求各贴了几个 `boy`、几个 `girl`。

## 核心观察

`boy` 只可能写出 `b`、`o`、`y`，`girl` 只可能写出 `g`、`i`、`r`、`l`。

**两套字母完全不重叠**，所以两种单词的计数互不干扰，可以分开做。

进一步：位置 $p$ 上出现 `b`，它不可能是别的单词写的，**只能是某个 `boy` 的第 1 个字符**。`o` 只能是某个 `boy` 的第 2 个，`y` 只能是第 3 个。

## 关键转化：按“单词起点”计数

与其一个个找完整的 `boy`（可能被打断），不如问一个等价的问题：

> 位置 $i$ 能不能是某个 `boy` 的起点？

答案只要看三个对齐位置：

- `s[i] == 'b'` —— 第 1 位露着，起点就是 $i$；
- `s[i+1] == 'o'` —— 第 1 位被盖住，但第 2 位露着，起点还是 $i$；
- `s[i+2] == 'y'` —— 前两位都被盖住，只露出第 3 位，起点依然是 $i$。

三者满足其一，就说明**存在一个以 $i$ 为起点的 `boy`**，计数加一。

`girl` 完全同理，只是对齐到 $i,\ i+1,\ i+2,\ i+3$ 四个位置。

## 为什么不会漏、不会重复

**不会漏**：题目保证每个单词至少有一个字符可见。对于以 $i$ 为起点的 `boy`，它可见的那一位必然落在 $i$、$i+1$、$i+2$ 之中，于是 $i$ 一定会被判定为起点。

**不会重复**：`b`、`o`、`y` 只能由 `boy` 写出，所以某个 `boy` 的字符只会出现在“它自己的起点 $+\,0/1/2$”这几个位置上，不可能跑到别的起点去。因此每个 $i$ 最多对应一个 `boy`，用 `||` 把三种情况合并也不会多算。

两条合起来：**每个 `boy` 恰好被数一次**。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.size();
    s += "    ";                 // 末尾补 4 位，保证 i+3 不越界
    // 其实也不用写，因为 string 会自己补
    int boy = 0, girl = 0;
    for (int i = 0; i < n; i++) {
        if (s[i] == 'b' || s[i + 1] == 'o' || s[i + 2] == 'y') boy++;
        if (s[i] == 'g' || s[i + 1] == 'i' || s[i + 2] == 'r' || s[i + 3] == 'l') girl++;
    }

    cout << boy << '\n' << girl << '\n';
    return 0;
}
```

## 复杂度

- 时间：$O(l)$，只扫一遍字符串。
- 空间：$O(1)$，除了读入的字符串没有额外数组。

## 细节

- 输入不含空格，直接 `cin >> s` 即可。
- 循环里会访问 `s[i+3]`，末尾补几位空字符可以让下标始终合法，比每处写 `if (i+3 < n)` 更省事。
- 补位后真实长度要提前存下来（`n = s.size()` 在补位之前取），否则循环会多跑几位。

## 附：另一种等价写法

也可以从“字母”角度切入：一个字母如果**不是接着同一个单词的上一个字母**，就说明它属于一个新词。

```cpp
for (int i = 1; i <= n; i++) {
    if (s[i]=='b' || (s[i]=='o' && s[i-1]!='b') || (s[i]=='y' && s[i-1]!='o')) boy++;
    if (s[i]=='g' || (s[i]=='i' && s[i-1]!='g') ||
        (s[i]=='r' && s[i-1]!='i') || (s[i]=='l' && s[i-1]!='r')) girl++;
}
```

两种写法的本质相同：都是在数**同一个单词的可见字符块**。按起点计数更直观，按字母判断则省掉了补位。
