# P1249 最大乘积

## 题意

将 n 拆成若干个互不相同的自然数，使乘积最大，输出分解方案和最大乘积。

## 贪心策略

**从 2 开始依次取数，再把剩余值从后往前分配，每次加 1，直到分配完毕。**

例如 n = 10：

```text
先取出：2、3、4，剩余 1
调整为：2、3、5，乘积 30
```

### 1. 为什么从 2 开始？

0 会使乘积为 0；1 可以合并到最大的数中，使乘积增大，因此不选。

选 k 个互不相同且至少为 2 的数，最小总和为：

$$
S_k=2+3+\cdots+(k+1)
$$

从 2 开始取数，能确定最大项数。

### 2. 为什么从后往前分配？

给 x 加 1，总乘积会乘上：

$$
\frac{x+1}{x}=1+\frac1x
$$

**x 越小，增加收益越大，但必须避免重复。**

连续整数中，只有最后一个数能直接增加；它增加后，前面的数才有增加的空间：

```text
2、3、4 → 2、3、5 → 2、4、5 → 3、4、5
```

后面的数加过一次后，应转向前面。例如：

```text
继续增加最大数：2、3、6，乘积 36
转而增加前一项：2、4、5，乘积 40
```

因此，从后往前分配，既能保持互不相同，又能避免剩余值过于集中。

### 3. 正确性说明

**固定项数时，这种分配最优。**

设升序方案为 a₁、a₂、……、aₖ，令 bᵢ = aᵢ − i，则 b 单调不减。

若最大、最小的 b 相差至少 2，就能在保持各项不同的前提下，将较大数中的 1 转给较小数，使乘积增加：

$$
(x+1)(y-1)-xy=y-x-1>0
$$

所以最优时，各个 b 至多相差 1。从后往前逐轮加 1，恰好得到这种形态：**连续整数，或连续整数中缺少一个数。**

**最大项数能够取得最优解。**

假设只有 m 项，但 n ≥ Sₘ₊₁。先将这 m 项调整为最优形态，设最小值为 d：

- **d = 2**：总和最多为 Sₘ + m − 1，小于 Sₘ₊₁，矛盾。
- **d ≥ 4**：设第二小的数为 y，将 d、y 换成 `2、d−1、y−1`，各项不同，且乘积增加，因为：

  $$
  2(d-1)(y-1)-dy=(d-2)(y-2)-2>0
  $$

- **d = 3**：由 n ≥ Sₘ₊₁，最优形态中必有一个缺少的数 g ≥ 4，且 g + 2 已被选入。将 g + 2 拆成 `2、g`，没有重复，且 2g > g + 2。

只有一项时，若还能拆成两项，则 n ≥ 5，拆成 `2、n−2` 同样更优。

因此，少于最大项数的方案不可能最优，贪心成立。

## 高精度

数组倒序保存乘积，初始为 1，再依次乘上每个选出的数，逐位处理进位即可。

## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    vector<int> a;

    // 确定最大项数
    for (int x = 2; n >= x; x++) {
        a.push_back(x);
        n -= x;
    }

    // 从后往前分配剩余值
    while (n > 0) {
        for (int i = (int)a.size() - 1; i >= 0 && n > 0; i--) {
            a[i]++;
            n--;
        }
    }

    for (int i = 0; i < (int)a.size(); i++) {
        if (i) cout << ' ';
        cout << a[i];
    }
    cout << '\n';

    // 高精度乘法
    vector<int> bits(1, 1);

    for (int x : a) {
        int carry = 0;
        for (int &digit : bits) {
            int cur = digit * x + carry;
            digit = cur % 10;
            carry = cur / 10;
        }
        while (carry) {
            bits.push_back(carry % 10);
            carry /= 10;
        }
    }

    for (int i = (int)bits.size() - 1; i >= 0; i--) {
        cout << bits[i];
    }
    cout << '\n';
}
```

## 复杂度与分类

设项数为 k，乘积位数为 D，其中 k = O(√n)。

- **时间复杂度**：O(kD)。
- **空间复杂度**：O(k + D)。

## 贪心分类

对应 **贪心分类** 贪心题单的 **§1.1 从最小/最大开始贪心**。

从最小有效值 2 开始，确定最大项数；再利用乘积性质，从后往前分配剩余值，得到该项数下的最大乘积。
