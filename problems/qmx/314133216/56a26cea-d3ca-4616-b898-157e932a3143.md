## 题意

有 $n$ 堆石子，第 $i$ 堆最初有 $a_i$ 颗石子。

每次操作选择一个非空石堆 $i$，取走一颗石子，并向前面的第 $\max(1,i-k)$ 堆到第 $i-1$ 堆各加入一颗石子。

Alice 先手，双方轮流操作，无法操作的人输。求最终获胜者。

## 从 k=1 推广到一般情况

当 $k=1$ 时，对第 $i$ 堆操作，相当于把一颗石子向左移动一堆；对第 $1$ 堆操作，则直接移除这颗石子。

因此，一颗最初位于第 $i$ 堆的石子，恰好需要 $i$ 次操作才能消失。

设 $M$ 为整局游戏的操作次数，则

$$
M=\sum_{i=1}^{n}a_i i.
$$

双方轮流操作，所以 $M$ 为奇数时 Alice 获胜，为偶数时 Bob 获胜。此时只需要统计奇数编号堆中的石子总数的奇偶性。

当 $k>1$ 时，一颗石子被取走后，会在前面的多个石堆中产生新石子。我们可以继续沿用上述思路，计算一颗石子连同它后续产生的所有石子，总共需要多少次操作才能全部消失。

设 $f_i$ 为一颗最初位于第 $i$ 堆的石子，以及它后续产生的所有石子，全部消失所需的操作次数。

第 $1$ 堆的石子操作一次就会消失，因此

$$
f_1=1.
$$

对于第 $i$ 堆的石子，先用一次操作取走它，再处理这次操作产生的新石子，所以

$$
\boxed{
f_i=1+\sum_{j=\max(1,i-k)}^{i-1}f_j
}.
$$

其中，$1$ 对应取走当前石子的操作，求和部分对应处理前面各堆新产生的石子。

不同石子之间不会抵消，也不会妨碍彼此被操作，因此每颗初始石子的贡献可以相加：

$$
\boxed{
M=\sum_{i=1}^{n}a_i f_i
}.
$$

这说明总操作次数由初始状态决定，与操作顺序无关。

更严格地，设 $b_i$ 为某一时刻第 $i$ 堆的石子数，设

$$
S=\sum_{i=1}^{n}b_i f_i.
$$

对第 $i$ 堆操作后，$S$ 的变化量恰好为

$$
-f_i+\sum_{j=\max(1,i-k)}^{i-1}f_j=-1.
$$

游戏结束时所有石堆为空，$S=0$，所以总操作次数就是 $S$ 的初值，即上面的 $M$。

当 $k=1$ 时，递推式变为 $f_i=1+f_{i-1}$，得到 $f_i=i$，与最开始的结论一致。

## 只计算奇偶性，寻找周期

$f_i$ 可能很大，但胜负只取决于 $M$ 的奇偶性，因此只需要保留每个 $f_i$ 的奇偶性。

设 $c_i=f_i\bmod 2$，则

$$
c_i\equiv
1+\sum_{j=\max(1,i-k)}^{i-1}c_j
\pmod 2.
$$

先看前 $k+1$ 项。

由 $f_1=1$，可得 $c_1=1$。

对于 $2\le i\le k+1$，依次递推可知，前面的项中只有 $c_1=1$，因此

$$
c_i\equiv1+1=0\pmod2.
$$

所以前 $k+1$ 项为

$$
1,\underbrace{0,0,\ldots,0}_{k\text{ 个}}.
$$

接下来比较相邻两项的递推式。对于 $i\ge k+2$，有

$$
\begin{aligned}
c_i
&\equiv1+c_{i-1}+c_{i-2}+\cdots+c_{i-k}
\pmod2,\\
c_{i-1}
&\equiv1+c_{i-2}+\cdots+c_{i-k}+c_{i-k-1}
\pmod2.
\end{aligned}
$$

两式相减并整理，得到

$$
c_i\equiv2c_{i-1}-c_{i-k-1}
\equiv c_{i-k-1}\pmod2.
$$

由于 $c_i$ 只能为 $0$ 或 $1$，因此

$$
\boxed{c_i=c_{i-k-1}}.
$$

也就是说，序列以 $k+1$ 为周期：

$$
1,\underbrace{0,\ldots,0}_{k\text{ 个}},
1,\underbrace{0,\ldots,0}_{k\text{ 个}},
\ldots
$$

所以

$$
c_i=
\begin{cases}
1,&(i-1)\bmod(k+1)=0,\\
0,&\text{其他情况}.
\end{cases}
$$

## 答案与实现

由

$$
M\bmod2=
\left(\sum_{i=1}^{n}a_i c_i\right)\bmod2,
$$

可知只有第

$$
1,\ k+2,\ 2k+3,\ \ldots
$$

堆的石子数会影响答案。

这些堆的石子总数为奇数时，Alice 获胜；否则 Bob 获胜。

读入时直接维护奇偶性即可，无须保存数组，也无须计算实际的操作次数。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    while (t--) {
        int n, k;
        cin >> n >> k;

        int parity = 0;

        for (int i = 1; i <= n; ++i) {
            int a;
            cin >> a;

            if ((i - 1) % (k + 1) == 0) {
                parity ^= (a & 1);
            }
        }

        cout << (parity ? "Alice\n" : "Bob\n");
    }

    return 0;
}
```

每组数据的时间复杂度为 $O(n)$，额外空间复杂度为 $O(1)$。

## Trick
生成规则固定、产生关系无环时，设 $f_i$ 为一个第 $i$ 类对象及其后续生成对象全部消失所需的操作次数，则

$$
f_i=1+\sum_{\text{本次生成的对象 }j}f_j.
$$

总操作次数等于各初始对象的贡献之和，与操作顺序无关。只关心奇偶性或余数时，直接对递推式取模；若递推含连续区间和，可通过相邻两式相减消去公共项，寻找周期。
