## 题目

洛谷 P1001：A+B Problem

题目链接：https://www.luogu.com.cn/problem/P1001

## 题意

读入两个整数 a 和 b，输出它们的和。

## 思路

使用标准输入读取两个整数，计算 a + b，再输出结果。

本题不需要复杂算法，重点是正确完成输入与输出。

## 错因分析

以下为演示错因：

1. 输出了额外的提示文字，例如“请输入两个数”，导致答案格式不符合要求。
2. 没有正确读取两个整数。
3. 把加法误写成其他运算。

提交到在线评测系统时，只输出题目要求的结果，不添加提示语。

## C++ 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << '\n';
    return 0;
}
```

## 正确性说明

程序读入 a 和 b 后，直接计算并输出 a + b，与题目要求一致。

## 复杂度

时间复杂度：O(1)。

额外空间复杂度：O(1)。

## 测试样例

输入：

```text
1 2
```

输出：

```text
3
```

补充检查：

- 输入 0 0，输出 0。
- 输入 -3 5，输出 2。
- 输入 -4 -6，输出 -10。
