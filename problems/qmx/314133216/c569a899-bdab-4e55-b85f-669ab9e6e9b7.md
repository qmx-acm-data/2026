# D - ABC|ABC|ABC 题解

**算法标签：枚举、线性 DP、前缀和、字符串。**

设两个切分点为 $i,j$，三段分别为：

$$
S_{1\ldots i},\qquad S_{i+1\ldots j},\qquad S_{j+1\ldots N}.
$$

我们需要统计三段都包含 `A/B/C` 的切分方案数。以下下标从 $1$ 开始。

## 做法一：枚举一个切分点，统计另一个

### 从暴力枚举出发

最直接的做法是枚举两个切分点 $i,j$，再判断三段是否合法。

即使用字符出现次数的前缀和，将每次判断优化到 $O(1)$，仍需枚举 $O(N^2)$ 对切分点，无法通过本题。

优化的关键是：**固定第二个切分点 $j$，能否直接算出有多少个合法的 $i$？**

为此，我们将三段的要求转化为切分点的取值范围。

### 第一段和第三段：确定边界

对于第一段，设：

$$
L=\max(\text{A、B、C 第一次出现的位置}).
$$

前缀至少延伸到 $L$，才能集齐三种字符。因此，第一段合法当且仅当：

$$
i\ge L.
$$

对于第三段，设：

$$
R=\min(\text{A、B、C 在全串中最后出现的位置})-1.
$$

切分点 $j$ 必须位于三种字符最后出现的位置之前，才能将它们都留在后缀中。因此，第三段合法当且仅当：

$$
j\le R.
$$

接下来，只需枚举 $1\le j\le R$，考虑中间一段的要求。如果整个字符串缺少某种字符，答案直接为 $0$。

### 中间一段：利用最近出现位置

扫描到位置 $j$ 时，记录 `A/B/C` 各自最近一次出现的位置，令它们的最小值为 $m_j$。尚未出现的字符，其位置记为 $0$。

要使中间一段 $S_{i+1\ldots j}$ 包含三种字符，这三个位置都必须在 $i$ 之后，即：

$$
i<m_j.
$$

例如，三个字符最近出现的位置分别为 $4,7,9$，那么 $i$ 最多只能取 $3$。否则，中间一段就会缺少最近出现于位置 $4$ 的那个字符。

结合第一段的要求，合法的 $i$ 恰好满足：

$$
L\le i<m_j.
$$

因此，**不必逐个枚举 $i$，直接计算这个区间内有多少个整数即可**。固定 $j$ 时的贡献为：

$$
\max(0,m_j-L).
$$

答案就是：

$$
\boxed{\displaystyle\sum_{j=1}^{R}\max(0,m_j-L)}.
$$

每种合法划分都有唯一的第二个切分点，因此不会重复计数。又因为 $L\ge1$、$i<m_j\le j$ 且 $j\le R<N$，三段都一定非空。

### 复杂度分析

先扫描一次，求出 $L,R$；再扫描 $j=1,\ldots,R$，维护三个字符最近出现的位置并累加贡献。

- 时间复杂度：$O(N)$。
- 额外空间复杂度：$O(1)$，不计输入字符串。

### C++17 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    string S;
    cin >> N >> S;

    array<int, 3> first{};
    array<int, 3> last{};

    for (int p = 1; p <= N; ++p) {
        int c = S[p - 1] - 'A';
        if (first[c] == 0) {
            first[c] = p;
        }
        last[c] = p;
    }

    if (min({first[0], first[1], first[2]}) == 0) {
        cout << 0 << '\n';
        return 0;
    }

    int L = max({first[0], first[1], first[2]});
    int R = min({last[0], last[1], last[2]}) - 1;

    array<int, 3> pos{};
    long long ans = 0;

    for (int j = 1; j <= R; ++j) {
        pos[S[j - 1] - 'A'] = j;
        int m = min({pos[0], pos[1], pos[2]});
        ans += max(0, m - L);
    }

    cout << ans << '\n';
    return 0;
}
```

## 做法二：线性 DP + 前缀和

第一种做法固定一个切分点，统计前面的划分方案。沿着这个思路，可以进一步定义：**将一个前缀划分成若干合法段，有多少种方案？**

称包含 `A/B/C` 的子串为合法段。

### 定义状态，枚举最后一段

设 $dp[k][i]$ 表示将前 $i$ 个字符恰好划分成 $k$ 个非空合法段的方案数。

初始状态为 $dp[0][0]=1$，其余状态为 $0$。答案为：

$$
dp[3][N].
$$

计算 $dp[k][i]$ 时，枚举最后一段之前的切分位置 $p$：

$$
\underbrace{S_{1\ldots p}}_{\text{划分成 }k-1\text{ 段}}
\ \big|\ 
\underbrace{S_{p+1\ldots i}}_{\text{最后一段}}.
$$

只要最后一段合法，就可以接在前面的任意一种合法划分之后。因此：

$$
dp[k][i]
=
\sum_{\substack{0\le p<i\\S_{p+1\ldots i}\text{ 合法}}}
dp[k-1][p].
$$

直接枚举 $p$，仍然需要 $O(N^2)$ 时间。

### 复用前面的性质，确定转移范围

第一种做法已经得到：

> 固定右端点 $i$，设三种字符最近出现位置的最小值为 $m_i$，则 $S_{p+1\ldots i}$ 合法，当且仅当 $p<m_i$。

于是，转移式可以写为：

$$
dp[k][i]=\sum_{p=0}^{m_i-1}dp[k-1][p].
$$

两种做法的联系也由此体现：

- 做法一：合法范围内，每个切分点贡献 $1$，直接计算数量。
- 做法二：合法范围内，每个切分点贡献 $dp[k-1][p]$，需要累加方案数。

### 用前缀和加速求和

合法的 $p$ 构成连续前缀，因此对上一层 DP 预处理：

$$
pre[t]=\sum_{p=0}^{t}dp[k-1][p].
$$

就能在 $O(1)$ 时间内完成一次转移：

$$
\boxed{
dp[k][i]=
\begin{cases}
0,&m_i=0,\\
pre[m_i-1],&m_i>0.
\end{cases}
}
$$

其中，$m_i=0$ 表示前 $i$ 个字符尚未集齐三种字符，无法形成合法的最后一段。

每种划分都有唯一的最后一个切分点，所以转移不会遗漏或重复；而 $p<m_i\le i$，也保证了最后一段非空。结合初始状态，依次计算即可得到答案。

### 复杂度分析

预处理所有 $m_i$，再依次计算 $k=1,2,3$ 三层 DP。每层先求上一层的前缀和，再计算当前层。

- 时间复杂度：$O(3N)=O(N)$。
- 空间复杂度：$O(N)$，使用滚动数组。

### C++17 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    string S;
    cin >> N >> S;

    // m[i]：截至位置 i，三种字符最后出现位置的最小值。
    vector<int> m(N + 1);
    array<int, 3> last{};

    for (int i = 1; i <= N; ++i) {
        last[S[i - 1] - 'A'] = i;
        m[i] = min({last[0], last[1], last[2]});
    }

    vector<long long> dp(N + 1, 0);
    vector<long long> ndp(N + 1, 0);
    vector<long long> pre(N + 1, 0);

    dp[0] = 1;

    for (int k = 1; k <= 3; ++k) {
        // 上一层 DP 的前缀和。
        pre[0] = dp[0];
        for (int i = 1; i <= N; ++i) {
            pre[i] = pre[i - 1] + dp[i];
        }

        fill(ndp.begin(), ndp.end(), 0);

        for (int i = 1; i <= N; ++i) {
            if (m[i] > 0) {
                ndp[i] = pre[m[i] - 1];
            }
        }

        dp.swap(ndp);
    }

    cout << dp[N] << '\n';
    return 0;
}
```

## 总结

两种做法都利用**字符最后出现的位置，确定合法左端点的范围**：做法一通过**枚举切分点 + 合法区间计数**直接统计方案；做法二通过**划分 DP + 前缀和优化**累加方案。

 **注：本题固定划分成三段，第一种做法更简洁；**
 **第二种做法可以自然推广到划分成指定的 $K$ 段，时间复杂度为 $O(KN)$。**
