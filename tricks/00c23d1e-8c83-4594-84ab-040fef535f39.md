# 环形数组下标回绕

## 简介

把数组看成钟表。越过末尾就回到开头，往左越过开头就回到末尾。常用于循环队列和约瑟夫环。

## 正文

设数组长度 `n > 0`，当前下标 `0 <= pos < n`，步数 `x >= 0`。以下运算使用有符号整数。

```cpp
auto step = x % n;
auto right = (pos + step) % n;
auto left = (pos - step + n) % n;
```

因为 `0 <= step < n`，`pos - step + n` 一定为正，向左走时直接加 `n` 再取余即可。当 `n = 5` 时，从下标 `0` 向左走两步得到 `(0 - 2 + 5) % 5 = 3`，从下标 `4` 向右走一步得到 `(4 + 1) % 5 = 0`。

如果中间加法可能超过 `int` 的范围，要在运算前把操作数提升到足够宽的有符号整数类型。

**口诀**　步数先去掉整圈，下标再回到数组范围内。
