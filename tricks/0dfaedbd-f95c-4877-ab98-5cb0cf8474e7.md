# 二分查找的边界更新

## 简介

判定结果随下标单调变化时，用二分找第一个或最后一个满足条件的位置。中位数的取法与边界更新配套，保证区间每次都能缩小。

## 正文

用 `while (l < r)` 搜索非空闭区间 `[l, r]`。若初始区间为空，直接返回无解。

| 目标 | 中位数 | 条件成立 | 条件不成立 |
| --- | --- | --- | --- |
| 找第一个满足的位置（假 → 真） | 左中位 `l + (r - l) / 2` | `r = mid` | `l = mid + 1` |
| 找最后一个满足的位置（真 → 假） | 右中位 `l + (r - l + 1) / 2` | `l = mid` | `r = mid - 1` |

例如，区间只剩 `[1, 2]` 时，左中位是 `1`，更新 `l = mid` 会卡住。右中位是 `2`，更新 `r = mid` 也会卡住。题目允许无解时，循环结束后还要验证 `l` 是否满足条件。

直接算 `(l + r) / 2` 可能使加法溢出。上表的公式需要保证括号里的差值及加法能用当前类型表示。C++20 可用 `<numeric>` 中的 `std::midpoint(l, r)` 取左中位，用 `std::midpoint(r, l)` 取右中位。

**口诀**　左中位配 `r = mid`，右中位配 `l = mid`。
