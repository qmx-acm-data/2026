# 正难则反

## 简介

正向操作难以维护，或目标难以直接计数时，可以倒转操作顺序、改数补集，或换一个观察方向。

## 正文

| 遇到什么 | 反过来怎么想 |
| --- | --- |
| 在无向图中依次删点，要求每一步的连通块数量 | 若操作全部已知，从删完后的图开始倒序加点，用并查集合并新点和仍在图中的邻点 |
| 合法区间难数，不合法区间好数 | 用总区间数减去不合法区间数 |
| 要求多个起点到同一终点的最短距离 | 无权有向图中，从终点沿反向边做一次 BFS |
| 每个人能看到谁不好维护 | 改看每个人会被谁看到，再根据题目的遮挡规则判断能否用单调栈 |

例如，长度为 `n` 的数组有 `n(n + 1) / 2` 个非空连续区间。若只容易数出含有 `0` 的区间，就用总数减去它们，得到不含 `0` 的区间数。

**口诀**　删得难就试着倒序加，目标难数就数补集，正向难搜就试着从终点出发。
