# 整数向上取整

## 简介

用整数运算计算分页数、分组数或装箱数，避免浮点精度误差。

## 正文

设 `a >= 0`，每组容量 `m > 0`。先算出能装满几组，剩下的物品再占一组。

```cpp
auto groups = a / m + (a % m != 0);
```

不过 **更简单的写法** 是，（当结果为正数的时候）

 向上取整 `(a + m - 1) / m`
 向下取整 `a / m`

使用前要确认中间加法能用当前整数类型表示。商加余数判断的写法省去了这一步加法。

例如，23 件物品每箱放 5 件，装满 4 箱后还剩 3 件，共需要 5 箱。若有 20 件，正好需要 4 箱。

**口诀**　整除就用商，有余数就加一。

**补充** 注意 int 自带的取整是向 0 取整，也就是当 被除数大于0时是向下取整，小于0就是向上取整。
所以上边的向上取整也同样。
